本資料は，物体領域検出とカテゴリアノテーションの分離に基づく粒度可変物体アノテーションの論文（再現元の `main.pdf` と再現実験の `paper/main.pdf`）について，手法と実験結果に関する質問とその回答を整理したものである．

# A. 手法の全体像

## Q1. この論文は何をしているのか

画像中の物体の場所を検出する部品（DETR）と，検出した物体にカテゴリ名を付与する部品（CLIP）を分離した手法である．
分離により，1回の検出結果に対して候補語彙を差し替えられるため，WordNetの下位語をたどって animal → dog → doberman のように粒度を段階的に変えたアノテーションを再学習なしに行える．

## Q2. 処理の流れはどうなっているのか

```text
画像 → DETR（1回のみ）→ クロップ（padで正方形化）
→ 深さ0：CLIPがCOCOの80クラスから1語を選ぶ（例：dog）
→ WordNetが，選ばれた1語の直接の下位語を辞書から取り出す（例：basenji等の18語）
→ 深さ1：同じクロップに対し，CLIPがその下位語から1語を選ぶ（例：basenji）
→ 下位語が存在しなくなるまで繰り返す
```

WordNetは新しい語を生成するのではなく，登録済みの下位語を取り出すだけである．
また，次の段階の候補語彙は，深さ0の語彙全体の下位語ではなく，前の段階で選ばれた1語の下位語のみである．
DETRの推論は最初の1回のみであり，以降の段階では同じクロップを再利用する．
出力は粗い語から細かい語への列と，各段階の確信度である．

## Q3. COCO以外の語を出力できたのは，CLIP自体が語を出力したためか

CLIPは語を生成するモデルではなく，与えられた候補語彙の中から画像に最も合う語を選ぶモデルである．
COCO外の語（camel等）を出力できたのは，COCO外の22語を候補語彙に追加したためである．
CLIPの利点は，語を追加するだけで，その語を再学習なしに認識できる点にある．
YOLOで同じ語を扱うには，画像の収集，アノテーション，再学習が必要である．
なお，深さ1以降の語（Arabian camel等）は人手で追加したものではなく，WordNetから自動的に得たものである．

## Q4. COCOの80クラスは何のために用いたのか

COCOの80クラスはデータセットの公式のカテゴリであり，本研究で作成したものではない．
人手で作成したのは，80クラスとWordNetのSynsetの対応表（例：fire hydrant → fireplug.n.01）と，COCO外の22語である．
80クラスを用いた理由は以下の3点である．

1. COCOの正解は80クラスで付与されているため，推定結果と正解を同じ語どうしで照合できる．
2. WordNetの階層をたどる出発点（深さ0）として，身の回りの物体を適度な粒度で表す語彙である．
3. 同じ80クラスで学習したYOLOと，同一の条件で比較できる．

手法自体は80クラスに依存しないが，深さ0で誤った語を選ぶと，以降の段階でも誤った分岐をたどるという弱点がある．

# B. 部品の選択

## Q5. なぜDETRを用いるのか

DETRはカテゴリ名の入力を必要とせず，1回の推論でバウンディングボックスを出力できる．
そのため，候補語彙を何度変更しても検出を再実行する必要がない．
位置検出精度もOWL-ViTやGrounding DINOと同程度であり，Non-Maximum Suppression（NMS）を必要としない点も扱いやすい．

## Q6. なぜDETRとCLIPの組み合わせを提案するのか

検出した領域をCLIPで分類する組み合わせ自体は既存であり，ViLD等でベースラインとして用いられている．
また，RegionCLIPは，画像全体と文章の組で学習したCLIPがクロップした領域の分類を苦手とすることを指摘している．
本研究の新規性は組み合わせではなく，1回の検出結果を再利用して粒度を段階的に変えるという使い方と，その性質の分析にある．
各部品には，分離の効果を明確にするために標準的なモデルを用いている．

## Q7. DETR以外の選択肢はないのか．DETRにしかできないことはあるか

DETRにしかできないことはない．
YOLO，RT-DETR，Region Proposal Network（RPN），Object Localization Network（OLN），Segment Anything（SAM），汎用的な語「object」を与えたGrounding DINO等で置き換えられる．
実際に，YOLO11xのボックスをCLIPで分類しても，Top-1正解率は提案手法と同じ0.604であった．
ただし，OWL-ViTやGrounding DINOも「object」で1回だけ検出すれば検出の再実行は不要であり，論文における比較の前提として留意が必要である．
DETRのスコアはCOCOのクラスらしさを表すため，COCOと外見が大きく異なる物体（灯台）は検出されなかった．
COCO外の物体を対象とする場合は，SAMやOLNのようにカテゴリに依存しない検出器が適している可能性がある．

# C. 前処理（pad と center）

## Q8. クロップは物体自身であるのに，なぜ pad や center が必要なのか．スコアは高くなるのか

CLIPは224×224ピクセルの正方形の画像のみを入力とするが，クロップは物体の形状に応じて縦長や横長になる．
そのため，クロップを正方形に変換する処理が必要であり，center と pad はその変換方法の違いである．

| 方法 | 処理 | 結果 |
| :---: | :--- | :--- |
| center | 短辺を224に縮小し，中央の正方形を切り出す（CLIPの標準の前処理） | 長辺方向の端が欠ける．瓶は book，電車は suitcase と誤った |
| pad | 黒の余白を加えて正方形にしてから縮小する | 物体の全体が残る．瓶は bottle（0.67），電車は train（0.97）となった |

pad により bottle の正解率は0.344から0.844に向上し，全体のTop-1正解率は約0.08向上した．
目的はスコアを上げることではなく物体の全体をCLIPに入力することであり，その結果として精度が向上した．
ただし，人物の正解率は約0.38のままであり，pad による改善は見られなかった．

## Q9. 単純に224×224に拡大縮小（引き伸ばし）することはできないのか

可能であり，CLIPは引き伸ばした画像も入力として受け付ける．
引き伸ばしは本研究では実験しておらず，精度への影響は未検証である．
歪みにより学習時と異なる見た目となるため精度が低下する可能性がある一方，物体が画像全体に写り pad より多くの画素を物体に使えるため精度が向上する可能性もある．
R-CNNでは，検出領域を引き伸ばし（warp）で正方形にする方法が良い結果を示している．
CLIPにおける効果を確認するには，`make_crop` に引き伸ばしを追加し，center，pad と比較する実験が必要である．

# D. 実験と結果の読み方

## Q10. 実験1（4.2節）は何をしているのか

カテゴリのアノテーションにCLIPのような視覚言語モデル（Vision-Language Model，VLM）が必要かを確かめる実験であり，検出は用いず画像全体を入力している．
ImageNetの1000クラスで学習したResNet50-IN1kと，2種類のCLIP（CLIP-RN50，CLIP-ViT-B/32）を比較した．
タスクAはCOCOの80クラスから選ぶ閉域評価，タスクBはキャプションから抽出した1371語から選ぶ広域評価である．

P@$`k`$ は上位 $`k`$ 語のうち正解の割合，R@$`k`$ は正解のうち上位 $`k`$ 語に含まれた割合である．
例えば，正解が3語の画像でCLIPが tie，person，handbag，wine glass，dining table の順に出力し，tie と person を含む3語が正解である場合，P@1 = 1.0，R@1 = 0.33，P@5 = 0.6，R@5 = 1.0となる．
タスクBのR@1が低いのは，1枚あたりの正解語が十数語あるという指標の性質による．

タスクAのP@1は，ResNet50-IN1kが0.216，CLIPが0.855であった．
COCOの80クラスのうちImageNetに同名のクラスが存在するのは19クラスのみであり，ResNet50-IN1kは person や dog を出力できない．
2種類のCLIPの差は小さく，性能を左右するのはモデルの構造（CNNかViTか）ではなく，学習方法と語彙の設計であることが示唆される．

## Q11. 図7とYOLOとの比較は深さ0のみか．図7は提案手法の結果か

YOLOとの比較は深さ0（COCOの80クラス）のみであり，4.8節の表5，図8，図9に示している．
図7はWordNetによる粒度可変アノテーションの定性結果であり，提案手法（DETRの閾値0.5，pad，CLIP-ViT-B/32，WordNet）で得た結果である．

## Q12. dog の確信度が低く下位語で高くなり，cat → domestic cat → Burmese cat で確信度が上下するのは良い結果か

確信度の上下のみでは良否を判断できず，手法の性質どおりの挙動である．
各段階の確信度はその段階の候補語彙の中での相対的な値であり，候補数が段階ごとに異なるため，深さ間で直接比較できない．

| 段階 | 選ばれた語 | 確信度 | 候補数 | 偶然の水準に対する倍率 |
| :---: | :---: | :---: | :---: | :---: |
| 深さ0 | dog | 0.389 | 80 | 約31倍 |
| 深さ1 | basenji | 0.671 | 18 | 約12倍 |
| 深さ0 | cat | 0.672 | 80 | 約54倍 |
| 深さ1 | domestic cat | 0.950 | 2 | 約1.9倍 |
| 深さ2 | Burmese cat | 0.354 | 15 | 約5.3倍 |

dog の確信度が低いのは，クロップ内に写る猫やソファのカテゴリと競合したためと考えられる．
一方で，候補語が互いに排他的でないこと（犬種と hunting dog，puppy 等の混在），細かい段階の正誤をCOCOでは検証できないこと，候補が1語の場合は必ず1.00となることが問題点として挙げられる．
対策として，各段階の確信度の積である累積確信度と，確信度と候補数の積を併記する方法がある．

## Q13. 表5でYOLO11xとYOLO11x + CLIPは同じ閾値なのに，なぜ $`n`$ が異なるのか

論文の表5では，同じ閾値であれば $`n`$ は一致している（閾値0.25で2210件，0.7で1474件）．
YOLO11x + CLIPはYOLO11xのボックスをそのまま用い，カテゴリの付与のみをCLIPに替えたものであるため，$`n`$ は必ず一致する．
$`n`$ が異なって見えるのはスライド16枚目の表であり，閾値の列を示さずに閾値0.25のYOLO11xと閾値0.7のYOLO11x + CLIPを並べたことによる．

# E. COCO外の語に対するYOLOとの比較

## Q14. YOLO11xではなく，YOLO11x + CLIPと比較する方が公平ではないか

YOLOは再学習が不可能なわけではなく，新しいクラスの画像とアノテーションを用意すれば追加学習できるが，その準備には大きな手間を要する．
論文の比較は，YOLOを再学習せずに用いた場合の限界を示すことを目的としている．
YOLO11x + CLIPは「提案手法の検出器をYOLOに替えたもの」であるため，提案手法との比較は検出器の比較となる．
この比較を追加すれば，設計が検出器に依存しないことの裏付けとなるが，COCO外の画像に対するYOLO11x + CLIPの実験は未実施である．
再学習なしに新しい語を扱えるという同一の条件で比較する相手としては，YOLO-Worldが最も適している．

## Q15. COCO外の語の比較は深さ0のみで，WordNetは用いていないのか

YOLOとの比較は深さ0のみである．
一方，4.6節の提案手法の実験では，COCO外の22語にもWordNetのSynsetを対応付けており，camel → Arabian camel，kangaroo → musk kangaroo のように深さ1以降もたどっている．
YOLOには下位語の仕組みがないため，深さ1以降は比較していない．

## Q16. この比較は不公平ではないか

深さ0で比較したこと自体は，YOLOに深さ1以降の出力がないための妥当な選択である．
しかし，以下の2点で不公平である．

1. 追加した22語は被写体を既知として選んだものであり，提案手法の候補語彙には正解が必ず含まれる．一方，YOLOの80クラスには正解が含まれない．
2. 評価に用いた画像は6枚のみである．

したがって，この比較は閉域モデルでは出力できない語を提案手法が再学習なしに出力できるという機能の違いを示すものであり，精度の優劣を示すものではない．
公平な比較とするには，被写体を見ずに定めた大規模な語彙（LVISの1203カテゴリ等）を用いること，YOLO-WorldやYOLO11x + CLIPに同じ語彙を与えること，評価画像を増やすことが必要である．

3. COCO外の画像に対するYOLO11x + CLIPの評価と，YOLO-Worldとの比較．
4. LVIS等を用いた深さ1以降の正解率の評価と，被写体を既知としない語彙での評価．

6. 論文における，COCO外の語の比較の限界の追記．
