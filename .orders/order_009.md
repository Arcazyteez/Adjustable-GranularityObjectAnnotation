# Order 009

## ユーザーの指示（原文）
```
以下の要求を追加してください、そして追加したものを現在のものを比較し、別のpdfで出力すること：
１．CLIPをSigLipを変更し再実験数る。目的は計算後のSoftMax関数をsigmoid関数に変更したい。
２．ハイブリットのところ、YOLOが出した深さ０とクロップされた画像をそのままCLIPに入れて計算。もしCLIPのスコアがYOLOのスコアより高いなら、CLIPの答えを使うこと。
３．ハイブリットのモデルで、MSCOCO以外の語彙にも対応したい。しかしYOLOが再学習が必要なので、実験の目的（学習なしでCOCO以外の語彙にも対応できる）とは逆になる。そこでCLIPをMSCOCOを使うではなく、WordNetで粗い語（深さ０）に使う。しかし、WordNetに出した語彙は必ずMSCOCOと同じ深さの語彙である。（おすすめはMSCOCOの語彙を参考し、WordNetのすべて同じ深さの語彙を調べる）
```

## 指示の解釈
新しい実験 `ex008` として以下の3点を追加し，現在の構成（ex007，CLIP-ViT-B/32 とソフトマックス）と比較する．
比較結果は既存の論文（paper/main.pdf）には反映せず，別のTeX文書（`paper_siglip_comparison/main.pdf`）として出力する．

1. **SigLIPへの変更（ソフトマックス → シグモイド）**
   - VLMを SigLIP（open_clip の `ViT-B-16-SigLIP`，webli）に変更し，各語のスコアを候補語彙で正規化するソフトマックスではなく，語ごとに独立なシグモイド $`\sigma(t\,\cos + b)`$ で計算する．
   - モデルの変更による効果と，正規化関数の変更による効果を分けるため，SigLIP にソフトマックスを用いる構成も比較に加える（同じ特徴から計算できるため追加の推論は不要）．
   - 現在の構成（CLIP + ソフトマックス）も同じプログラムで再計算し，ex007 と一致することを確認する．
2. **YOLOとVLMのスコアの比較による深さ0の決定（hybrid_cmp）**
   - YOLOが出力したボックスのクロップをそのままVLMに入力し，候補語彙上の最大スコアの語を求める．
   - VLMの最大スコアがYOLOの検出スコアより高い場合はVLMの語を，そうでない場合はYOLOの語を深さ0とする．
   - YOLOの語に対するVLMのスコアも記録する．
3. **WordNetの同じ深さの語彙による深さ0の候補（*_wn）**
   - YOLOの再学習を行わずにCOCO外の語に対応するため，VLMの深さ0の候補語彙をWordNetから作る．
   - WordNetの絶対的な深さは経路によって大きく異なる（例：dogは深さ8と13の経路を持つ）ため，COCOの各カテゴリのSynsetから最長の上位語の経路で $`k`$ 段上の祖先をとり，その祖先からちょうど $`k`$ 段下にあるSynset（COCOのカテゴリと同じ深さの「いとこ」）を候補とする．
   - 物理的な実体（physical_entity.n.01の下位語）に限り，COCOのカテゴリの上位語・下位語は除き（粒度がCOCOと異なるため），SemCorの出現頻度が1以上の語に限る．$`k \in \{1, 2, 3\}`$ を比較し，主要な結果は $`k = 2`$（681語）とする．
   - 2と組み合わせた構成（hybrid_cmp_wn）と，DETR + VLM で深さ0をこの語彙から選ぶ構成（proposed_wn）を評価する．
- 評価はex007と同じ分割（dev500，test500，lvis_dev，lvis_test）と指標（深さ0のTop-1，誤りの伝播とAUROC，LVISの hP/hR/hF，累積確信度による停止）で行う．閾値は提案手法 $`\theta \in \{0.5, 0.97\}`$，YOLO11x $`\in \{0.25, 0.7\}`$ とする．
- ex004の実画像（COCO外の物体）で定性評価を行う．
