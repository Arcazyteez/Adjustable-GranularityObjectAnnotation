# Order 023

## ユーザーの指示（原文）
```
論文とスライドの図のアノテーションの語彙をスコアを示してほしい、それぞれの確信度を知りたい
```

## 指示の解釈
論文とスライドの出力例の図では，各ボックスに出力した単語とアノテーションのスコア（式(9)）を1つずつ表示している．
粗い語から出力した単語までの経路上の各単語の確信度は表示していない．
そこで，図の各アノテーションについて，経路上の全ての単語とその確信度を示す．

### 対象の図
- **論文の図5，スライドの出力例（提案手法，ex015a）：**
  - 各ボックスに番号を付け，図の下に番号ごとの経路と各単語のスコア（式(10) の r）を並べる．
  - YOLO11xのボックスは1語のみのため，その語のアノテーションのスコア s を示す．
  - 読める分量にするため，表示する加えた領域を画像ごとにスコアの上位4件に減らす（従来は8件）．
- **論文の図1（予備実験，ex012，切り抜き画像＋CLIP・SigLIP）：** この手法には確率のスコアが無い．そのため，各単語の画像との類似度（コサイン類似度）を確信度の代わりに示し，確率ではないことを図の説明に明記する．
