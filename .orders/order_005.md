# Order 005

## ユーザーの指示（原文）
```
質問したものをまとめてください、発表のやり方を無視して
```
```
.pdfにpaperのフォルダに出力してください
```

## 指示の解釈
`main.pdf`（再現元の論文）と `paper/main.pdf`（再現実験の論文）について，チャットで行った質疑応答のうち，論文と手法に関するものを整理し，PDFとして `paper/` に出力する．

- 対象は手法の全体像，部品の選択，前処理，実験結果の読み方，YOLOとの比較に関する16件の質問とその回答とする．
- 発表に関する質問（スライドの構成，学会での発表，想定質問）と，Remote Controlの接続に関するやり取りは含めない．
- 回答の内容はチャットでの回答と整合させ，実施していない実験の結果は記述しない．
- 原稿はMarkdownで `paper/qa_summary.md` として保持し，pandoc（LuaLaTeX，ltjsarticle）で `paper/qa_summary.pdf` を生成する．
