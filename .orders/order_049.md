# order_049

## ユーザーの指示
> 両方とも閾値0.5で比較したら？それのほうが公平じゃないの？

## 解釈
- 検出だけの比較で，YOLO11x（既定 0.25）と DETR（0.5）の閾値が異なるため，両方を同じ閾値 0.5 にそろえて比較し直す．
- ただし，YOLO と DETR のスコアは計算方法が異なり（YOLO：物体らしさとクラスの確率，DETR：クラスのソフトマックス確率），同じ値でも意味が同じとは限らない．そこで次の3通りで比べる．
  1. 同じ閾値（0.5〜0.9）
  2. 同じ箱の数（DETR の閾値を，検証用の画像で YOLO11x と1枚あたりの箱の数が同じになるように決める）
  3. 従来の既定値（YOLO 0.25，DETR 0.5）
- 新しい推論は行わず，ex017 で保存した検出結果（YOLO はスコア 0.25 以上，DETR は 0.5 以上を保存）を数え直す．ex022 の軽微な変更として ex022b とする．
- 指標：1枚あたりの箱の数，COCO の物体の再現率（全体，人物，人物以外），正解に当たらない箱の割合，LVIS による COCO 外の物体の再現率．dev と test の両方を保存する．
