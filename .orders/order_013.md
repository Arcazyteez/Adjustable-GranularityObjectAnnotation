## 指示の解釈
`進捗報告_2026B.pdf` のアルゴリズム「粒度可変アノテーション」と評価方法を，これまでの論文・レポート・実験結果を用いずに，新しい実験 `ex012` として実装する．

### アルゴリズム（進捗報告のとおり）
- **入力：** 物体認識モデル $`D`$（YOLO，DETR），文章・画像埋め込みモデル $`F`$（CLIP，SigLIP），語彙レベルが最も高い単語の集合 $`\mathcal{W}`$，画像 $`X`$，類似と判断する下限値 $`\theta`$
- **手順：**
  1. $`\mathcal{B} = D(X)`$ でボックスを得る．
  2. 各ボックス $`B_i`$ について，切り抜き画像 $`X_i`$ の特徴ベクトル $`v_{X_i} = F(X_i)`$ を求める．
  3. 単語の集合 $`\mathcal{W}`$ の特徴ベクトルとの類似度（コサイン類似度）が最大の単語 $`w_{j^*}`$ を選ぶ．
  4. 類似度が $`\theta`$ 未満なら，そのボックスは終了する．
  5. そうでなければ $`(B_i, w_{j^*})`$ を出力し，$`\mathcal{W}`$ を $`w_{j^*}`$ の下位語の集合に置き換えて3に戻る．下位語が無ければ終了する．
- **実装上の決定：**
  - 類似度は，画像特徴とプロンプト「a photo of a {単語}」のテキスト特徴のコサイン類似度とする．
  - 切り抜き画像は，ボックスで切り抜いた画像を黒で正方形にパディングしたものとする．
  - 下位語はWordNetの直接の下位語とし，単語はSynsetの先頭のレンマとする．

### 定量評価
- **条件：** 初期の語彙 $`\mathcal{W}`$ をMS COCOの80クラスとし，下位語の集合は生成しない（1段階のみ）．
- **データ：** COCO 2017 val の5000枚を2つに分け，前半2500枚（検証用）で $`\theta`$ を選び，後半2500枚（テスト用）で報告する．
- **組み合わせ：** $`D \in \{\text{YOLO11x}, \text{DETR}\}`$，$`F \in \{\text{CLIP ViT-B/32}, \text{SigLIP ViT-B/16}\}`$ の全組み合わせを評価する．
- **予測精度：**
  - ラベルの一致率：IoU 0.5以上で対応したボックスのうち，クラスが一致した割合
  - ボックスのずれ：対応したボックスのIoU，中心のずれ，座標の誤差
  - クラスを含めた適合率・再現率・F値
  - COCOの mAP
- **比較：** Close Vocabularyモデル（YOLO11x，DETRのクラス出力）の予測精度と比較する．同じ検出器のボックスで比べることで，分類の違いのみを比較できる．

### 定性評価
- **条件：** 初期の語彙 $`\mathcal{W}`$ をWordNetの上位語とする．WordNetの最上位カテゴリ（noun.Tops）のうち物体を表す person，animal，plant，food，artifact，natural object の6語を用いる．
- **内容：** COCOの画像に対して，ボックスと，粗い語から細かい語までのクラスを予測し，図として示す．
