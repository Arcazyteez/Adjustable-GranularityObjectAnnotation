## ユーザーの指示
@VG.pdf この論文を参考して、私の提案手法で実装してください。論文に書いてある手法を使わないこと。MSCOCOデータセットは検証用なもの、粒度変更まで進んでください。以上で実験を再開しましょう。

## 解釈
- 「私の提案手法」：order_029・order_030 の新しい提案手法 OWLv2（objectness）+ Alpha-CLIP（context1.5）+ WordNet とする．
- 「論文に書いてある手法を使わない」：VG.pdf の手法は用いない．用いないのは以下である．
  - Visual Genome の頻度に基づく語彙
  - 人手で定めた最上位の枠と中間階層（WordNet，埋め込みのクラスタリング）
  - 上から下への木の命名
  - 部分木の確率の合計による命名
  - SigLIP
  深さ0の語彙は COCO の80クラス，細分化は前稿と同じ WordNet の直接の下位語をたどる手順のままとする．
- 「参考して」：VG.pdf の評価の考え方だけを参考にする．
  - 階層的適合率・再現率・F値（hP，hR，hF．文献[16]の評価指標で，命名の手法ではない）
  - 正解ボックスで検出の影響を除いた評価
  - 深さ（粒度）と正しさの交換の分析
- 「MSCOCO は検証用」：データは MSCOCO val2017 のみ（ex017・ex019 と同じ dev 500枚，test 500枚）とする．LVIS と VG は用いない．
- 「粒度変更まで進む」：深さ0（COCO の80クラス）だけでなく，WordNet の下位語による深さ1以降の細分化まで評価する．
  - COCO の注釈は80クラスしかない．そこで，同じ MSCOCO の captions_val2017 のキャプションに現れる名詞のうち，正解クラスの Synset の下位語になる語を細かい粒度の正解とする．例：person → man，woman，skier
  - 評価の単位はインスタンスで，その画像の同じクラスのインスタンスにはキャプションの語の集合を共有させる．
- 比較：
  - 古い提案手法 DETR + CLIP-ViT-B/32
  - 検出器を YOLO11x にした YOLO11x + CLIP-ViT-B/32（report_030 で VLM を用いる構成の中の最良）
  - 正解ボックス + 各 F
- 実験番号：評価の対象（細分化の正しさ）と正解の作り方が変わるため，新しい実験 ex020 とする．ex019 の検出・特徴のキャッシュと dev で選んだ深さ0の θ を再利用する．
