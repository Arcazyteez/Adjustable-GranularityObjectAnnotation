# Order 003

## ユーザーの指示（原文）
```
YOLOモデルと性能を比較したい、YOLO自体のvocabularyを使って実験再開しましょう。それを完成したら現在の論文にも追加してください
```

## 指示の解釈
提案パイプライン（DETR + 局所クロップ + CLIP-ViT-B/32）と，閉域的な物体検出モデルであるYOLOを比較する実験を新たに実施し，その結果を `paper/` の論文に追記する．

- 「YOLO自体のvocabulary」は，YOLOが学習したCOCOの80クラスと解釈する．YOLOは検出と同時にこの80クラスのいずれかを出力するため，提案手法の第1段階（候補語彙＝COCO 80クラス）と同じ語彙で比較できる．
- YOLOは学習済みモデル（Ultralytics YOLO11 n/m/x，YOLOv8x）を用い，追加学習は行わない．COCO train2017で学習済みのため，評価に用いるval2017は学習に含まれない．
- 比較は以下の3種類とする．
  1. COCO val2017の500枚（ex003と同じseed=42のサンプル）におけるカテゴリアノテーション精度．YOLOのボックスをGTとIoU 0.5以上で1対1に対応付け，予測ラベルのTop-1/Top-5正解率を計算する．さらに，提案手法とYOLOの両方が検出した共通のGTインスタンスに限定した比較と，YOLOのボックスをCLIPで分類する組合せ（YOLO-box + CLIP）による比較を行い，検出器と分類器の寄与を切り分ける．
  2. ex002と同じ4画像におけるクラス非依存の位置検出精度（Recall@IoU0.5，平均最良IoU）．
  3. ex004と同じCOCO外の語を含む実画像6枚に対する定性比較（YOLOは80クラスにない物体を正しく命名できないことの確認）．
- 実験は新たな問題設定のため `programs/ex005_coco_val500_yolo_comparison/` とする．
