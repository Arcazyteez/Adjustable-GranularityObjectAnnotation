いや、論文の方法を使ってもいい、提案手法だけ（SigLip）使わないことです。そしてハイブリット手法も消してください、これから使わないと思います。比較したいものはOwL+Alpha CLip+Wordnet, DETR+CLIP+WordNet, YOLOの3つだけです。論文にあるVGのやり方などを現在の実験に追加してほしい。

## 解釈
- **order_031 の解釈の訂正：** VG.pdf の手法は使ってよい．使わないのは SigLIP だけである．VG.pdf の手法は，F を各手法のもの（新しい提案手法は Alpha-CLIP，古い提案手法は CLIP-ViT-B/32）に置き換えて適用する．
  - 「提案手法だけ使わない」は，VG.pdf の提案手法（部分木の確率の合計）を使わないとも読める．そこで，部分木の確率の合計は他の命名の手順と分けて報告し，外しても結論が分かるようにする．
- **ハイブリッド手法の削除：** ユーザーに確認し，範囲を「現在の実験から外す」とした．
  - ex019・ex020 の YOLO11x + F（CLIP，Alpha-CLIP）の構成を，比較・表・図から外す．
  - その結果フォルダと特徴のキャッシュは削除した．
  - ex006〜ex011 のプログラムと結果は残す．
- **比較する3手法：**
  1. OWLv2 + Alpha-CLIP + WordNet（新しい提案手法．OWLv2@20，joint）
  2. DETR + CLIP-ViT-B/32 + WordNet（古い提案手法）
  3. YOLO11x 単体（COCO のクラスのみを出力する）
  OWLv2@20 + CLIP-B/32，CLIP-ViT-B/16 などの補助の比較も外す．
- **VG.pdf のやり方の追加（ex020 に追加する．実験条件の履歴は train.py の docstring に残す）：**
  - VG の語彙：Visual Genome の物体の注釈（v1.2．v1.4 の物体の注釈は公開元に無い）の Synset の出現頻度から作る．
    - COCO val2017 と重複する画像は集計から除く．
    - 条件は $`n_{\min} = 10`$，深さ5以上とする．
    - プロンプトには VG で最も多く使われた名前を用いる．
  - 枠と木：最上位の枠（40個．VG.pdf に一覧が無いため自分で定めた）と WordNet の上下関係で，VG の語彙の木を作る．COCO の80クラスの Synset も木に加える．
  - 命名の手順（深さ0の棄却 θ0 と残すボックスは ex019 と同じにして，命名の手順だけを比べる）：
    1. WordNet の直接の下位語による細分化（これまでの手順）
    2. VG の木による細分化（深さ0の COCO のクラスから，VG の木の子をたどる）
    3. VG の語彙の平坦な命名
    4. 部分木の確率の合計（VG.pdf の提案手法の集約．VLM は SigLIP ではなく各手法の F）
    閾値などは dev の hF で選ぶ．
- **評価：** VG.pdf の式(8)に合わせる．
  - 出力と正解の Synset 自身と，深さ4以上の上位語の集合で hP，hR，hF を求める．
  - 例外として，COCO の80クラスの Synset は深さによらず含める（person の深さは3のため）．
  - 命名の正解率と完全一致率も求める．
  - 細かい正解は order_031 と同じく COCO のキャプションから作る．
  - VLM を用いない語彙の被覆率も求める．
