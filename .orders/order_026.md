# Order 026

## ユーザーの指示（原文）
```
MSCOCO以外について、提案手法が深さ０から間違って、それから間違い粒度に変更していく。例えKangarooは正解だけど、ditchに認識されたこと。これらのところを知りたい。
```

## 指示の解釈
COCO外の物体（LVISのGTのうちCOCOの80クラス以外）について，提案手法（greedy：確率を上位語へ集約し，上位語から貪欲に下位語へ進む）が，経路の最初の段階（深さ0）で誤った上位語を選び，その後も誤った枝の中で細かい語へ進んでしまう事例（例：GTが kangaroo なのに ditch と命名）を調べる．

- **対象：** テスト用の画像で，COCO外のGTとIoU 0.5以上で対応した加えた領域（ex015b の paired naming と同じ対応付け）．OWLv2の重みは ST（主）と FT（参考）．
- **分析：**
  1. 経路のどの深さで正解の枝（GTのSynsetの上位語の集合）から外れたか（分岐の深さ）の分布．深さ0で外れた割合．
  2. 外れた段階で，正解の枝の確率と選んだ枝の確率，正解の枝の順位．
  3. 外れた後に経路がどれだけ深く進んだか（誤った粒度の深さ）．
  4. 深さ0で外れた場合の，GTの上位の分類（動物，食べ物，人工物等）と選んだ枝の組の頻度．
  5. 確率が最大の1語（flat）なら正しかった割合．
  6. kangaroo → ditch のような具体例を画像付きで示す．
- **実験番号：** ex015b の出力の分析で問題設定は変えないため，`ex015c_divergence_analysis` とする．
- **論文・スライド：** 今回は分析と報告のみとし，反映は結果を見て判断する（指示があれば反映する）．
- **その他：** テスト，`document.md`，`visualize_result.ipynb`，`report_026.md` とPDFを作成・更新する．
