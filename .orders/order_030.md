## 解釈
- ex019（order_029）の再実験である．比較手法とOWLの条件を追加する軽微な変更のため，ex019 のプログラムを拡張し，既存の結果はスキップして再利用する．
- YOLO の比較：YOLO11x（conf 0.25，ex017 のキャッシュ）を
  1. Close Vocabulary モデル単体（YOLO 自身のクラスと検出スコア．θ は検出スコアに対して dev で選ぶ）
  2. 検出器として用いた YOLO11x + F（CLIP-ViT-B/32，CLIP-ViT-B/16，Alpha-CLIP）+ WordNet
  の両方で評価する．
- OWL の閾値：dev の平均ボックス数が20個/枚と50個/枚になる閾値に固定した条件を，全ての F と棄却のスコアで評価する（θ は各条件で dev の F値で選ぶ）．order_029 の dev で選んだ10個/枚の結果も比較に残す．
- 評価は MSCOCO のみ（ex017・ex019 と同じ dev/test）．性能（Top-1，適合率，再現率，F値，人物・人物以外の再現率）と速度を比較し，対応のあるブートストラップで差を検定する．
- 比較画像は古い提案手法，YOLO11x，新しい提案手法（20個/枚，50個/枚）を並べる．
