# order_029

## ユーザーの指示
実験を進めましょう。変更があるのでお願いします。新しい提案手法は「OwL＋Alpha　CLIP＋WordNet」の方法で実験してください。今回MSCOCO以外の実験は行いません。新しい提案手法と古い提案手法を比較した、どちらの性能やパフォーマンスがいいのを知りたい

## 解釈
- 新しい提案手法：OWLv2（objectness，クラス非依存）で領域を検出し，Alpha-CLIP で「画像全体 + ボックスの領域を示すαチャネル」から語を選び，WordNet の下位語で細分化する．
  - ex018 の結果から，OWL はクエリではなく objectness を用いる．
  - Alpha-CLIP には分割マスクが無いため，ボックスの内側を1とする矩形のαを与える．
- 古い提案手法：論文の DETR + CLIP-ViT-B/32 + WordNet（切り抜き画像，ソフトマックス）．
- 評価は MSCOCO のみ（LVIS は使わない）．ex017 と同じ COCO val2017 の dev 500枚（ボックス数と θ の選択）と test 500枚（報告）．
  - 性能：深さ0（COCOの80クラス）のラベルの Top-1/Top-5，適合率・再現率・F値，位置の再現率と IoU．θ（確信度による棄却）なし・ありの両方．
  - パフォーマンス：1枚あたりの検出・アノテーションの時間，ボックス数．
  - 深さ1以降は COCO に正解が無いため，深さごとの確信度と定性的な例で示す．
- どの要素が効いたかを分けるため，検出器 {DETR, OWLv2} × 命名 {CLIP 切り抜き, Alpha-CLIP} の組み合わせも比較する（CLIP は Alpha-CLIP と同じ ViT-B/16 と，論文の ViT-B/32）．
- 前回の「提案手法とハイブリッド手法を消す」は，古い提案手法との比較が求められたため実施しない（既存のプログラム・結果は残す）．
- 新しい実験 `programs/ex019_coco_owl_alphaclip_wordnet/` を作る．
