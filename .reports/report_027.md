# report_027：main.pdf と進捗報告_2026B.pdf の統合実装（ex017）

## 1. 概要

- **指示：** `main.pdf`（論文）と `進捗報告_2026B.pdf`（Alg. 粒度可変アノテーションと評価方法）の内容を，新しいフォルダに実装する．
- **実施内容：** 新しい実験フォルダ `programs/ex017_coco_granular_annotation/` に，2つのPDFの手法と評価を自己完結の形で実装した．`programs/common/` や ex001〜ex016 のモジュール・結果は読み込まない．COCO の画像・注釈と学習済みの重みのみを用いる．その上で，論文4章と進捗報告の評価に対応する E1〜E6 を全て実行した．
- **主な結論：**
  1. **オープンボキャブラリな F が必要（論文4.2節を再現）．** ResNet50-IN1k と CLIP・SigLIP の差は，タスクA・Bの全指標で有意だった（Wilcoxon，最大でも $`p = 4.4 \times 10^{-15}`$）．CLIP-RN50 と CLIP-ViT-B/32 の差は，タスクBでは有意でなかった．
  2. **位置検出の精度：** test 500枚では，DETR（Recall@IoU0.5 0.738）が OWL-ViT（0.565）と Grounding DINO（0.681）を上回った．DETR の検出は 0.049 秒/枚，切り抜き画像のアノテーションは 0.020 秒/枚（CLIP-ViT-B/32）だった．語彙を変えるたびに必要なのは後者だけであり，Grounding DINO は検出だけで 0.44 秒/枚かかる．
  3. **定量評価（進捗報告）：** 同じボックスで比べると，ラベルの一致率は Close Vocabularyモデル（DETR 0.963，YOLO11x 0.974）が提案手法（0.56〜0.69）を大きく上回る．DETR + CLIP-ViT-B/32 の Top-1 は 0.560 で，論文の 0.647 より低い（原因は 4.3 節）．$`\theta`$ による棄却で Top-1 と適合率は上がるが，F値の改善は小さい．
  4. **深さごとの確信度（論文4.5節を再現）：** 深さ0から深さ1で平均確信度が大きく下がる（CLIP 0.583 → 0.358，SigLIP 0.817 → 0.521）．コサイン類似度（進捗報告の similarity）は深さによらず約0.26でほぼ一定である．そのため，1つの $`\theta`$ では深さごとの信頼性を区別できない．
  5. **定性評価：** COCO外の物体は第1段階で正しく命名された（penguin，helicopter，kangaroo，camel，確信度 0.93〜0.99）．一方，細分化（emperor penguin，musk kangaroo）は画像の種と合っていない．灯台の塔は今回も検出されず，「lighthouse」は隣の家に付いた．WordNetの上位語から始めると，person の下で leader → torchbearer のような視覚的でない語に進む．

## 2. 実装（`programs/ex017_coco_granular_annotation/`）

| ファイル | 内容 |
| :--- | :--- |
| `data.py` | COCO の読み込み，seed 42 による dev/test 各500枚の分割，切り抜き画像 `make_crop`，語彙（COCO 80，COCO外の22語，WordNetの上位語6語，キャプションの名詞・動詞），WordNet の直接の下位語 `hyponym_vocab` |
| `model.py` | D：DETR（閾値0.5），YOLO11x（0.25），OWL-ViT，Grounding DINO．F：ResNet50-IN1k，CLIP-RN50，CLIP-ViT-B/32，SigLIP-ViT-B/16．Alg. の While ループ `granular_annotation` と全体の `annotate_image` |
| `train.py` | E1〜E6 の実行と評価（`metrics_func`），θ の選択，図の作成 |

**アルゴリズム（進捗報告の Alg.）：** $`\mathcal{B} = D(X)`$ を1回だけ求める．各ボックスの切り抜き画像 $`X_i`$ の特徴 $`v_{X_i} = F(X_i)`$ と，語彙の特徴 $`\mathcal{V} = F(\mathcal{W})`$ のスコアが最大の単語 $`w_{j^*}`$ を選ぶ．スコアが $`\theta`$ 未満なら終了し，$`\theta`$ 以上なら $`(B_i, w_{j^*})`$ を出力して $`\mathcal{W}`$ を $`w_{j^*}`$ の下位語に置き換える．下位語が無ければ終了する．

- **スコア：** 進捗報告のコサイン類似度（`cosine`）と，論文の候補語彙内のソフトマックス（`softmax`）の2種類を実装した．論文の設定は $`\theta = -\infty`$ に相当する．
- **プロンプト：** 「a photo of a {w}」．
- **下位語：** WordNet の直接の下位語（インスタンスの下位語を除く）．単語は Synset の先頭のレンマとする．

**切り抜き画像：** ボックスにちょうど合わせて切り抜き（周囲は含めない），黒で正方形にパディングする．CLIP・SigLIP の前処理は中央を正方形に切り抜くため，パディングしないと細長い物体の一部が失われる．test の DETR + CLIP-ViT-B/32 で確認した結果，パディングで Top-1 は 0.496 から 0.560 に，Top-5 は 0.752 から 0.830 に上がった．そこで，パディングありを採用した．

**データ：** COCO 2017 val のうち，物体の注釈を持つ画像から seed 42 で1000枚を選び，dev 500枚（$`\theta`$ の選択）と test 500枚（報告）に分けた．推論は RTX 4070 Ti（12GB）で行い，全体で約15分かかった．

- **表の見方：** Top-1・Top-5 は，クラスを問わず IoU 0.5 以上で GT と対応したボックスにおけるラベルの一致率である．適合率・再現率・F値は，クラスの一致も含めて求めた．θ は dev の F値が最大になる値を選んだ．Top-1 と F値の95%信頼区間は `E3_quantitative/*/test/0/metrics.json` にある．
- **ボックスのずれ：** 同じ D なら，Close Vocabularyモデルと提案手法でボックスは同じである．DETR の平均IoU は 0.813，中心のずれは GT の対角線の 4.6%，座標の誤差は平均 4.3 ピクセルだった．YOLO11x では 0.877，3.0%，3.2 ピクセルである．θ で棄却すると，残ったボックスの IoU はわずかに上がる．
- **Close Vocabularyモデルとの比較：** COCO 80クラスの範囲では，ラベルの一致率・F値ともに Close Vocabularyモデルが大きく上回る（DETR：0.963 対 0.560．信頼区間は重ならない）．提案手法の利点は，COCO外の語彙と粒度の変更にある（3.5節）．
- **θ の効果：** ソフトマックスの θ は，Top-1（CLIP で 0.560 → 0.625）と適合率を上げるが，F値の改善は 0.04 以下である．コサイン類似度の θ は CLIP ではほとんど効かず（F値 0.321 → 0.318），YOLO11x では θ = −∞ が選ばれた．
- **論文の Top-1 0.647 との差：** 今回の 0.560 との差には，DETR の閾値が影響している．追加の確認では，同じ test の DETR のボックスを検出スコア 0.9 以上に絞ると，Top-1 は 0.597，Top-5 は 0.871 になった（パディングあり）．論文の対応数（500枚で1466件）は今回（2521件）より少なく，より高い検出の閾値を使ったと考えられる．

## 5. 未解決の論点と次の候補

- **DETR の閾値：** 0.5 で固定した．論文の対応数（1466件）に近づける閾値（0.9〜0.97）で E3・E4 を再実行し，論文の Top-1 0.647 が再現できるかは確認していない．
- **θ の定義：** コサイン類似度は深さによらずほぼ一定であり，進捗報告の1つの θ では細分化を止められない．深さや候補数に応じた θ，ソフトマックスの確信度，親の語との差を用いた停止などの比較が候補になる．
- **WordNet の絞り込み：** 上位語から始めると，person の下の役割の語（leader，divider）や絶滅種に進む．視覚的なカテゴリへの絞り込みが必要である．
- **細分化の正しさの評価：** COCO には細かい粒度の正解が無い．emperor penguin や musk kangaroo の誤りを定量化するには，LVIS などの注釈が必要である．
- **論文・スライド：** 指示が無いため，今回の結果は反映していない．
