# report_003：閉域物体検出モデルYOLOとの比較と論文への追記

## 1. 概要

提案パイプライン（DETR + 局所クロップ + CLIP-ViT-B/32）と，COCOの80クラスで学習した閉域物体検出モデルYOLOを，YOLO自体の語彙（COCOの80クラス）で比較した（ex005）．
結果を論文 `paper/main.pdf` の4.8節として追記し，関連する箇所も修正した．
修正箇所は赤字で示している．

| 比較 | 主な結果 |
| :--- | :--- |
| COCO 80クラスでのカテゴリアノテーション精度 | YOLOのTop-1は0.957〜0.993で，提案手法（0.560〜0.604）を大きく上回る |
| 共通GTインスタンスでの比較 | YOLO11x 0.989 vs 提案手法 0.609（1480件，McNemar検定で $` p < 10^{-150} `$ ） |
| 差の要因 | YOLO11xのボックスをCLIPで分類すると0.565〜0.604となり，提案手法とほぼ一致した．差は検出器ではなく分類器に起因する |
| 位置検出精度（4画像） | YOLOv8x 0.800 / 0.767，YOLO11x 0.700 / 0.719（Recall@IoU0.5 / 平均最良IoU）．DETRの0.800 / 0.705と同程度 |
| COCO外の語の実画像 | YOLOは penguin→bird，camel→dog，kangaroo→bear / sheep，helicopter→airplane．灯台は検出なし |

## 2. 実験条件

`programs/ex005_coco_val500_yolo_comparison/`，結果は `outputs/ex005_coco_val500_yolo_comparison/` に保存した．

| 項目 | 設定 |
| :--- | :--- |
| YOLO | Ultralytics 8.3.170の学習済みモデル YOLO11n，YOLO11m，YOLO11x，YOLOv8x（COCO train2017で学習済み，追加学習なし） |
| 語彙 | YOLOのクラス名はCOCOの80クラス名と完全一致することを確認した |
| 検出スコアの閾値 | 0.25（既定値），0.5，0.7．NMSのIoU閾値は既定値の0.7 |
| 評価画像 | ex003と同じseed=42の500枚（GTインスタンス3206件），ex002の4画像，ex004の実画像6枚 |
| 対応付け | ハンガリアン法でIoU 0.5以上の1対1対応 |
| Top-5 | NMSの `return_idxs` で残ったアンカーを特定し，生出力の80クラスのスコアから上位5件を取得した（Top-1はYOLOの出力ラベルと一致することを確認） |
| 正命名率 $` r `$ | Top-1が正解したインスタンス数をGTインスタンス総数（3206件）で割った値．手法間で対応インスタンス数が異なるため導入した |
| 共通GTでの比較 | YOLOとex003（CLIP-ViT-B/32，pad， $` \theta = 0.5 `$ と0.97）の両方が対応付けたGTインスタンスでTop-1を比較し，正確なMcNemar検定（二項検定）を行った |
| YOLO-box + CLIP | YOLO11xの対応インスタンスのクロップをpadでCLIP-ViT-B/32に入力し，COCOの80クラスで分類した |

実行時間は全条件で107秒，ピークVRAMは1.8GB，ピークRAMは3.9GBであり，並列数は1とした．

## 5. 考察

COCOの80クラスで教師あり学習したYOLOは，同じ80クラスの範囲内では，ゼロショットのCLIPを用いる提案手法より大幅に高精度である．
YOLO11x + CLIPの結果から，この差は分類器の差であり，DETRを検出器に用いたことによる不利ではない．
したがって，論文の主張は「80クラス内での精度」ではなく，「学習時の語彙を超えた語や粒度でのアノテーションを再学習なしに行えること」に置く必要があり，論文の5.1節をそのように修正した．
一方，COCO外の物体に対しては，YOLOは最も近い80クラスの語（bird，dog，bear等）を高い確信度で出力するため，誤りに気付きにくいという問題もある．

## 6. 未解決の論点と次に検討すべき作業の候補

1. **YOLOとVLMの組合せ**：YOLOの予測を深さ0とし，深さ1以降の細分化のみをCLIPで行う組合せ（論文5.5節の第六の課題）は未実施である．80クラス内の精度と粒度可変性を両立できるかを評価できる．ex005の `instances.json` とex003の階層アノテーションの関数を再利用すれば短時間で実施できる．
2. **COCO外の物体に対するYOLOの誤りの定量化**：ex004の6枚のみの定性比較である．LVISやOpenImagesのようにCOCO外のカテゴリを含むデータセットで，YOLOと提案手法の正命名率を比較することが考えられる．
3. **人物クラスの誤り**：提案手法とYOLOの差の大部分は人物クラスによる．プロンプトの設計等で人物の誤りを改善できれば，差を縮められる可能性がある．
4. **論文の分量**：11ページになった．投稿先のページ制限によっては，表5または図8のどちらかを削るなどの調整が必要である．
5. **赤字の扱い**：次の修正依頼があった場合は，規約に従い今回の赤字を黒字に戻した上で新たな修正箇所のみを赤字にする．
