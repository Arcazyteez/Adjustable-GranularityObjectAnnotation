# report_015：再学習なしでCOCO外の語彙の物体を検出する粒度可変アノテーション（ex013）

## 1. 概要

ex012（進捗報告2026Bのアルゴリズム）を土台に，提案した改善をおすすめの順番で実施した．目的は，再学習なしで MS COCO 以外の語彙の物体を検出し，粒度可変のアノテーションを行うことである．プログラムは `programs/ex013_open_vocabulary_granular/` である．

構成は，前の構成に改善を1つずつ加えて比較した．

| 構成 | 内容 |
| :--- | :--- |
| ex012 | YOLO11x のボックスに，WordNet の上位語6語から下位語を葉までたどる（θ = −1） |
| A_root | 提案A（前半）：YOLO11x のボックスの深さ0を YOLO11x のクラスとし，深さ1以降を F と WordNet で細分化する |
| A_add | 提案A（後半）：YOLO11x と重ならない OWLv2 の物体らしさの上位10件の領域を加え，上位語6語から命名する |
| B_prune | 提案B：WordNet の下位語を絞り込む．COCO train2017 のキャプションに出る語を3個以上含む枝と，キャプションに出る深さ8以上の語だけを残す（animal の下位語は47 → 7） |
| BD_stop | 提案D：候補の中でのソフトマックスが τ 以上の間だけ細分化する．候補が1つの段階は，親より類似度が高いときだけ進む |
| BDC_look | 提案C：子と孫の類似度の最大値で，進む枝を選ぶ（2段の先読み） |
| BDE_strong | 提案E：BD_stop に，SigLIP SO400M，上位語を含むプロンプト，1.5倍に広げた切り抜きを加える |
| BDCE_all | すべてを加える |

### 評価の条件

| 項目 | 内容 |
| :--- | :--- |
| データ | COCO 2017 val のうち LVIS の注釈がある画像．ex012 と同じ半分ずつに分けた（検証用2387枚，テスト用2365枚） |
| GT | LVIS の注釈（WordNet の Synset 付き）．COCO 外の物体は13150件，COCO の物体は11765件（テスト用） |
| COCO 外の物体の定義 | COCO のクラスの Synset の上位語・下位語・自身ではなく，レンマ名も COCO のクラス名と一致しないもの |
| 対応付け | 出力ボックスと GT を，IoU 0.5以上で1対1に対応付けた |
| 検出 | GT に出力ボックスが対応した割合 |
| 命名 | 出力した語が GT の上位語・自身・下位語のいずれかで，深さ3以上の語である割合 |
| 細分化 | 出力した語が GT の語に到達した割合（GT より細かい語を含む） |
| hP / hR / hF | 上位語を含めた Synset の集合による階層的な適合率・再現率・F 値．深さ3以上で whole.n.02 を除く．LVIS の注釈は網羅的でないため，GT と対応しない出力は hP に含めない |
| τ の決め方 | 検証用の画像で hF が最大になる値を選んだ |

### 分かったこと

- **前提（評価）：** ex012 をそのまま使うと，COCO 外の物体の検出は7.6%で，命名はほぼ0%だった．上位語から葉まで止めずにたどると，COCO の物体でも正しく命名できたのは1.2%だった．
- **提案A（前半，YOLO のクラスを深さ0に）：** COCO の物体の命名が1.2%から37.4%になり，hF は0.058から0.352に上がった．
- **提案A（後半，OWLv2 で補完）：** COCO 外の物体の検出が7.6%から36.0%（4.8倍）になった．ただし，葉まで止めずにたどる段階では，命名は0.2%にとどまった．
- **提案B（絞り込み）：** 単独では効果が小さかった（命名0.3%）．役割の語を除いても，葉まで止めずにたどると，誤った細かい語に行き着くためである．
- **提案D（止める基準）：** COCO 外の命名が6.8%に，COCO の命名が43.9%に上がった．選ばれた τ は0.95と高く，ほとんどのボックスが深さ0（上位語6語，または YOLO のクラス）で止まった（平均の深さ0.10）．
- **提案C（先読み）：** COCO 外の命名が13.7%（ex012 から大幅増，D に対して2倍），加えた領域の正解率が9.7%になり，hF も最高の0.364になった．
- **提案E（SO400M ＋ 上位語を含むプロンプト ＋ 拡大した切り抜き）：** 期待に反して命名は下がった（BD_stop の6.8%に対して1.9%，BDC_look の13.7%に対して10.7%）．一方，平均の深さ（0.28）と細分化（0.24%）は最も高く，より深くまで進むようになった．3つの変更を同時に加えたので，どれが原因かは切り分けられていない．
- **COCO の物体：** 止める基準と先読みによって，命名は37%から44%に上がった．

### 定性評価（`outputs/ex013_open_vocabulary_granular/qualitative/grid_*.png`）

- **細分化できた例：**
  - YOLO の枠では bench > park bench，cup > coffee cup．
  - 加えた領域では，時計塔が artifact > structure > tower，布が artifact > … > cloth covering になった．
- **粗い語で止まる例：** 加えた領域の多くは，artifact，natural object，food のような上位語で止まった．
- **問題点：** 物体の一部や背景にも natural object などの語が付いた．

## 3. 考察

- **検出は改善した：** 検出の補完（A）で，COCO 外の物体の多くに枠が付くようになった．
- **名前付けの改善は粗い語が中心：** 命名の改善の大部分は，止める基準（D）と先読み（C）による「正しい粗い語での停止」による．COCO 外の物体を LVIS の語まで細分化できたのは，0.1〜0.2%にとどまった．
- **深さ0の上位語がボトルネック：** 6語（person，animal，plant，food，artifact，natural object）は粗すぎて，そこから先へ確信を持って進めない．深さ0の候補に，もう少し細かい中間の語（vehicle，furniture，container など）を含めることが次の課題である．
- **提案E の結果は条件しだい：** 大きいモデルにすると深くまで進むようになるが，命名率は下がった．プロンプトや切り抜きの変更を切り分けて調べる必要がある．

## 5. 未解決の論点と次の候補

- **深さ0の語彙：** 上位語6語を，キャプションによく出るカテゴリの語（vehicle，furniture，container，bird，fruit など）に広げる．
- **提案E の切り分け：** SO400M，プロンプト，切り抜きを1つずつ評価する．
- **停止の閾値：** τ は検証用の hF で選ぶと高くなり，粗い語で止まりやすい．細分化を重視した選び方も試す必要がある．
- **加えた領域の扱い：** 加えた領域の正解率は最大9.7%で，物体の一部や背景にも語が付く．確信度による棄却を加える．
- **評価の範囲：** seed は42の1つだけである．LVIS の注釈が網羅的でないため，適合率は低めに出ている．
- **tokens.json：** ファイルがないため，ai-agent による検証は行っていない．
