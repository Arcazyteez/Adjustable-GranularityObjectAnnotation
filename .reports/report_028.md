# report_028：OWLの領域検出の確認（ex018）

## 1. 概要

- **指示：** 提案手法（DETR + CLIP/SigLIP + WordNet）とハイブリッド手法（YOLO11x + VLM + WordNet）を廃し，OWL → SigLIP → WordNet の新しいパイプラインで再実験する．その前段として，OWLが画像の物体の領域を検出（クロップ）できるかを確認する．
- **実施内容：** 確認のみを行った．既存手法の削除と新しいパイプラインでの再実験は未実施である．LVIS v1 val のGTを用い，(1) YOLO11x が検出できる領域をOWLも検出できるか，(2) YOLO11x が検出できない領域をOWLが検出できるか，を3つのOWLの条件で測った．
- **主な結論：**
  1. **YOLOが検出できる領域は，OWLv2もほぼ検出できる．** 1枚あたり平均20個のボックス（閾値0.143）の OWLv2 の物体らしさ（objectness）は，YOLOが検出したCOCOの物体のGTの93.9%を検出した．平均50個では97.5%である．
  2. **YOLOが検出できない領域を，OWLv2の objectness は検出できる．** YOLOが見逃したCOCO外の物体（帽子，靴，ジャージ，ベーグルなど）のGTのうち，平均20個で49.5%（95%信頼区間 [0.445, 0.550]），平均50個で71.6%を検出した．YOLOが見逃したCOCOの物体（小さい人物・遠くの車など）も53.8%（平均20個）を検出した．
  3. **新しいパイプラインの検出器は OWLv2 の objectness が適する．** COCOの80クラスをクエリとするOWLv2は，COCOの物体ではobjectnessより少し高い（P(OWL|YOLO検出) 0.961）．しかし，YOLOが見逃したCOCO外の物体は12.6%しか検出しない．OWL-ViT（B/32）はいずれの指標でも大きく劣る．
  4. **注意点：** OWLのボックスはYOLO（平均6.2個/枚）より多い．YOLOのボックスの19.6%（平均20個の場合）はOWLのボックスとIoU 0.5以上で重ならず，主に密集した小さい人物・椅子・遠くの車である．

## 2. 実験設定（`programs/ex018_owl_region_check/`）

| ファイル | 内容 |
| :--- | :--- |
| `data.py` | LVIS v1 val の読み込み．Synset が COCOのクラスのSynsetの上位語・下位語・自身（またはレンマ名がクラス名と一致）なら「COCOの物体」，それ以外を「COCO外の物体」とする．ex017 の分割・YOLO11x と OWL-ViT の検出のキャッシュを読み込む |
| `model.py` | `OWLv2Detector`：OWLv2（`google/owlv2-base-patch16-ensemble`）の1回の推論から，COCOの80クラスのクエリのスコア（最大値）と objectness の2種類の検出を得る（クラス非依存のNMS IoU 0.5，上位300件）．`covered`：IoU 0.5 以上の重なりの判定 |
| `train.py` | 予算（1枚あたりの平均ボックス数）を揃えた閾値 `budget_threshold`，GTの4分割の集計 `metrics_func`，ブートストラップの95%信頼区間，閾値の掃引，比較画像 |

- **画像：** ex017 の test 500枚のうち，LVIS の注釈がある474枚．GTはCOCOの物体2650件とCOCO外の物体2687件である．
- **YOLO11x：** conf 0.25（Ultralyticsの既定値），平均6.2個/枚．ex017 の検出のキャッシュを用いた．
- **OWLの条件：** OWL-ViT（B/32，COCOの80クラスのクエリ，ex017 のキャッシュで閾値0.1以上のみ保存，平均8.2個/枚），OWLv2 のクエリ（COCOの80クラス），OWLv2 の objectness（クラス非依存）．
- **動作点：** OWLのボックス数は閾値で大きく変わる．そこで，平均ボックス数が10，20，50個になる閾値（スコアのみから決め，GTは見ない）と固定の閾値0.1で比べた．OWL-ViT はキャッシュの都合上，全ての動作点が閾値0.1（8.2個/枚）と同じになる．
- **判定：** GTに対して IoU 0.5 以上のボックスが1つでもあれば検出とする（提案領域の再現率と同じ判定）．各GTを「両方が検出」「YOLOのみ」「OWLのみ」「どちらも検出しない」に分ける．
  - P(OWL | YOLO検出)：YOLOが検出したGTのうち，OWLも検出した割合（確認項目1）
  - P(OWL | YOLO見逃し)：YOLOが見逃したGTのうち，OWLが検出した割合（確認項目2）

## 3. 結果

### 3.1 動作点ごとの結果

| 条件 | 平均ボックス数 | YOLOのボックスの被覆率 | COCO：P(OWL\|YOLO検出) | COCO：P(OWL\|YOLO見逃し) | COCO外：P(OWL\|YOLO見逃し) [95%CI] |
| :--- | ---: | ---: | ---: | ---: | :--- |
| OWL-ViT クエリ（閾値0.1） | 8.2 | 0.676 | 0.759 | 0.106 | 0.068 [0.053, 0.086] |
| OWLv2 クエリ（10個） | 10 | 0.624 | 0.910 | 0.482 | 0.072 [0.052, 0.097] |
| OWLv2 クエリ（20個） | 20 | 0.841 | **0.961** | **0.580** | 0.126 [0.100, 0.154] |
| OWLv2 クエリ（50個） | 50 | 0.964 | 0.984 | 0.671 | 0.303 [0.263, 0.341] |
| OWLv2 objectness（10個） | 10 | 0.611 | 0.865 | 0.389 | 0.302 [0.261, 0.354] |
| OWLv2 objectness（20個） | 20 | 0.804 | 0.939 | 0.538 | **0.495 [0.445, 0.550]** |
| OWLv2 objectness（50個） | 50 | 0.956 | 0.975 | 0.644 | **0.716 [0.664, 0.765]** |
| OWLv2 objectness（閾値0.1） | 34.0 | 0.925 | 0.969 | 0.611 | 0.632 [0.580, 0.690] |

YOLOのボックスの被覆率は，YOLOのボックスのうちOWLのボックスと IoU 0.5 以上で重なる割合である（YOLOの誤検出を含む）．GTと重なるYOLOのボックスに限ると，objectness（20個）は0.941，（50個）は0.978である．なお，LVISのCOCOの物体に対するYOLOの再現率は0.407にとどまる．これは，LVISが小さい物体・密集した物体まで注釈し，COCOのクラスの下位語（例：bagel，doughnut）も「COCOの物体」に含むためである．

![YOLOとOWLの比較（(a) YOLOが検出したCOCOの物体をOWLも検出した割合，(b) YOLOが見逃した物体をOWLが検出した割合，横軸は1枚あたりの平均ボックス数，(c) 平均20個の動作点でのGTの4分割）](../outputs/ex018_owl_region_check/fig_summary.png)

- **確認項目1：** 平均ボックス数を増やすと，どのOWLv2の条件もYOLOが検出したCOCOの物体をほぼ全て含む（約30個以上で0.96以上）．同じボックス数ではクエリの方が objectness より少し高い．
- **確認項目2：** COCO外の物体では，objectness がクエリを全ての予算で大きく上回る（20個で0.495対0.126）．クエリはCOCOの80クラスに似た物体しか拾わないためである．COCOの物体の見逃しは両者で大差ない．

## 5. 未解決の論点と次の候補

- **既存手法の削除と新しいパイプラインでの再実験（未実施）：** 本確認の結果，新しいパイプラインの検出器には OWLv2 の objectness を用いるのが妥当である．次は，提案手法とハイブリッド手法を論文・プログラムから削除し，OWLv2 objectness → SigLIP → WordNet で再実験する．削除の範囲（論文の節・図表，ex003〜ex017 のプログラムと結果）は確認が必要である．
- **OWLのボックス数の決め方：** 平均20個ではYOLOが検出した物体の約6%を見逃し，50個では見逃しが2.5%まで減るが，物体でない領域も増える．固定の閾値ではなく，画像ごとの上位K件や，objectness とクエリのスコアの併用を検討する．
- **余分なボックス：** objectness（20個）のボックスの75.1%はYOLOのボックスと重ならず，そのうちLVISのGTと重なるのは28.4%である．ただし，LVISの注釈は網羅的でない（federated）ため，GTと重ならないことは誤りを意味しない．新しいパイプラインでは SigLIP の確信度による棄却（進捗報告の θ）がこの役割を担う．
- **ボックスの重複：** objectness は人物全体と服・靴のように入れ子のボックスを出す．粒度可変アノテーションでは部分と全体の関係として利用できる可能性がある．
