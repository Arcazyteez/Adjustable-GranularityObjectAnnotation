# report_030：YOLO11x の追加と OWLv2 のボックス数の固定（20個/枚，50個/枚）による再実験（ex019）

## 1. 概要

- **目的：** report_029 の比較（新しい提案手法 OWLv2 + Alpha-CLIP + WordNet，古い提案手法 DETR + CLIP-ViT-B/32 + WordNet）に YOLO11x を加える．さらに，OWLv2 のボックス数を20個/枚と50個/枚に固定した条件も評価する．
- **データ：** MSCOCO val2017 のみ（ex017・ex019 と同じ dev 500枚，test 500枚）．$`\theta`$ は各条件で dev の F値で選び，test で報告した．
- **追加した比較：**
  - YOLO11x 単体（Close Vocabulary モデル．YOLO 自身のクラスと検出スコア，conf 0.25）
  - YOLO11x を検出器とした YOLO11x + F（CLIP-ViT-B/32，CLIP-ViT-B/16，Alpha-CLIP）+ WordNet
- **主な結論：**
  1. **COCO の80クラスでは YOLO11x 単体が圧倒的に強い．** Top-1 0.976，F値 0.719 で，全ての VLM を用いる構成の約2倍の F値である．処理も最速である（0.018秒/枚）．
  2. **VLM を用いる構成の中では，YOLO11x + CLIP-ViT-B/32 の F値が最も高い（0.458）．** 古い提案手法（0.378）も新しい提案手法（0.331〜0.340）も上回った．YOLO のボックスは位置が正確で（平均 IoU 0.889），数が少ないため誤検出が少ない．
  3. **OWLv2 を20個/枚・50個/枚に増やしても，F値は上がらなかった．**
     - 50個/枚では，クラス非依存の再現率は DETR・YOLO を上回る（0.875，人物 0.883）．$`\theta`$ なしのクラスを含めた再現率も0.466で，古い提案手法（0.435）より高い．
     - ただし，誤検出が多く，適合率は0.069まで下がった．
     - $`\theta`$ で棄却すると，物体らしさと確信度の積（joint）の $`\theta = 0.169`$ が，事実上「物体らしさ ≥ 0.169」の条件になる．この条件は20個/枚の閾値（0.149）より厳しい．そのため，20個/枚と50個/枚の結果は完全に一致した（F値 0.331）．
     - VLM の確信度だけで棄却すると，50個/枚の F値は0.221まで下がる．
  4. **Top-1 は新しい提案手法が高く，F値は低い傾向は変わらない．** 20個/枚の新しい提案手法は，古い提案手法に対して Top-1 が +0.134（[0.103, 0.164]），F値が −0.048（[−0.075, −0.019]，$`p = 0.001`$）である．
  5. **Alpha-CLIP は OWLv2 のボックスでのみ有効．** YOLO・DETR のボックスでは，CLIP-ViT-B/32 より Top-1・F値ともに低い．YOLO + Alpha-CLIP（joint）の F値は0.419，YOLO + CLIP-ViT-B/32 は0.458 である．

## 5. 未解決の論点と次の候補

- **棄却の方法が最大の課題：** OWLv2@50 は物体の87.5%を囲み，命名できる物体も最も多い．しかし，現在の棄却のスコア（VLM の確信度，物体らしさとの積）では，正しいボックスだけを残せない．
  - 候補1：クラスごとの NMS（同じ名前の重複ボックスの除去）
  - 候補2：部分と全体の包含関係による統合
  - 候補3：OWLv2 のテキストクエリのスコア（例：COCO の80クラス）を棄却に使う
- **YOLO11x を土台にする構成：** COCO の範囲では YOLO11x 単体が最も正確で速い．以前のハイブリッド構成（深さ0を YOLO のクラスとし，深さ1以降を VLM と WordNet で細分化する）が，COCO の評価では最も有利である．
- **評価の範囲：** COCO の80クラスの評価は YOLO11x に有利である．OWLv2 の利点（COCO 外の物体，部分の検出）と細分化の正しさは，この評価では測れない．研究の主張を「COCO での精度」にするか，「COCO 外の物体・細かい粒度への対応」にするかを決める必要がある．
