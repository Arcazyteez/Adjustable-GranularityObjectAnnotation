# report_019：再学習なしの粒度可変アノテーションのやり直し（ex015），論文の書き直し，発表スライド

## 1. 概要

ex014までの結果から改善策を提案し，おすすめの順番で実験をやり直した（ex015）．その結果に合わせて `paper_2026B` を書き直し，発表スライド `slides_2026B.pptx` を新しく作成した．

- **目標：** モデルの再学習なしで，物体認識モデルが学習していない物体と語彙を検出・命名する．精度はできるだけ高くする．
- **プログラム：** `programs/ex015_lvis_open_vocabulary_annotation/`（`data.py`，`model.py`，`train.py`，`analysis.py`）
- **評価：** ex013・ex014と同じ方法．LVISのアノテーションがある画像（検証用2387枚，テスト用2365枚）を用い，テスト用ではCOCO外の物体が13150件である．
- **設定の選び方：** 設定はすべて検証用の画像で選び，結果はテスト用の画像で報告する．

### 実施した順番（おすすめ順）

| 段階 | 内容 | 選んだ設定 |
| :--- | :--- | :--- |
| S0 | 原因の切り分け：OWLv2にLVISの語彙とキャプションの語彙を与えて，1位の単語の正解率を比べる | – |
| S1 | 語の選び方：flat，deepest，backoff，greedy（上位語から貪欲に進む）と，温度 β | greedy，β = 2，τ = 0.1 |
| S2 | 文章（plain，定義文，両者の平均）と語彙（人の役割を表す語を除くか） | 平均，人の役割を除く |
| S3 | YOLO11xのボックスを，クラスの下位語へ細分化する | 細分化しない（検証用で選ばれず） |
| S4 | 加える領域の数 K と，物体らしさの下限 o | K = 100，o = 0.02（hF_fed 基準） |
| S5 | OWLv2の重みの比較 | ST，ST-L，FT |

### OWLv2の重み

| 名前 | 重み | 位置づけ |
| :--- | :--- | :--- |
| ST | `google/owlv2-base-patch16` | 自己学習のみで，LVISの人手の注釈を使っていない．**主な条件** |
| ST-L | `google/owlv2-large-patch14` | 自己学習のみの大きいモデル |
| FT | `google/owlv2-base-patch16-ensemble` | LVISで微調整済み．評価カテゴリを学習時に見ているため参考値 |

ex013・ex014ではFTを使っていた．今回は「学習時に無い物体」という目標に合わせて，STを主な条件にした．

### 評価指標で追加したもの

LVISは全ての物体に注釈があるわけではない．そこで，GTと対応しない出力の扱いを変えて，3通りの hF を求めた．

| 指標 | GTと対応しない出力の扱い |
| :--- | :--- |
| hF | 除く（ex013と同じ） |
| hF_fed | LVISの評価方法に倣う．存在しないと確認されたカテゴリか，網羅的に注釈されたカテゴリの語（またはその下位語）を出力した場合だけ誤りとする |
| hF_strict | 全て誤りとする |

### 分かったこと

- **最も効果が大きかったのは K：**
  - K を10から100に増やすと，STでもCOCO外の物体の検出は21.2% → 56.0%，命名は5.5% → 21.1%，細分化は1.9% → 7.3%になった．
  - 以前の版（ex013，FT使用）は命名13.7%，細分化0.1%だった．LVISの注釈を使わないSTでも，これを上回った．
- **確率を集約して止める効果：**
  - 1語を選ぶだけ（flat）では，細かい語は出るが誤りが多く，命名は3.4%だった．
  - 確率を上位語へ集約し確信度で止めると，命名は5〜6%になり，hF_fed も上がった．
  - ただし差は小さい．
- **文章と語彙の整理（S2）：** COCO外の hR が0.076から0.085に上がった．
- **YOLOのボックスの細分化（S3）：** 効果はなかった．検証用の画像では，細分化しない設定が選ばれた．
- **適合率とのトレードオフ：**
  - K = 100では，加えた領域のうち正しく命名できたものは1.9%しかない．
  - hF_strict で選ぶと o = 0.3 になる．適合率は10.5%に上がるが，加える領域は1画像あたり2件で，命名は1.8%に落ちる．
  - 網羅性と適合率のどちらを重視するかで，設定が大きく変わる．
- **ST-L（大きいモデル）：**
  - 同じ設定で，細分化が7.3% → 13.3%，COCO外の hR が0.264 → 0.289に上がった．より細かい単語まで正しく進んだ．
  - 命名（20.3%）と hF_fed（0.481）は，STと同程度かやや低かった．
  - β と τ はSTで選んだ値を使っており，ST-L用には選び直していない．
- **FT（参考）：** 同じ設定で命名35.5%，細分化28.1%だった．STとの差には，LVISでの微調整の効果が含まれる．

### 定性評価（`outputs/ex015_lvis_open_vocabulary_annotation/qualitative/`，論文の図4）

- **STで正しく付いた例：** ski parka，ski boot，stick，sausage，bun，sauce，tower などは，COCO外の物体に正しい単語が付いた．
- **STの弱点：**
  - device，instrumentality，structure などの粗い語で止まる領域が多い．
  - 画像の大部分を覆う領域や物体の一部にも，単語が付く．
- **FT：** goggles，ski pole，clock tower，gargoyle，catsup のように，細かい語まで進む領域が多い．

## 6. 未解決の論点と次の候補

- **適合率が低い：** 加えた領域の適合率が低い（STで1.9%）．確率の集中度（エントロピー）による棄却を試す価値がある．
- **評価の幅：** LVISは全ての物体に注釈があるわけではない．hF_fed と hF_strict は，真の値の上限と下限に近いと考えられる．真の適合率は，GTと対応しない出力を人手で確認しないと分からない．
- **領域の分類能力：** 学習時に無い物体に対する領域の分類能力が，主な限界である．SigLIP SO400M等の特徴と領域の特徴を組み合わせる方法が候補になる．
- **評価の範囲：** seed は42の1つだけである．
- **ai-agent による検証：** `tokens.json` が無いため，行っていない．
