# report_031：提案手法（OWLv2 + Alpha-CLIP + WordNet）の粒度の変更までの評価（ex020）

## 1. 概要

- **目的：** 提案手法の評価を，深さ0（COCO の80クラス）の命名から，WordNet の下位語による細分化（深さ1以降．粒度の変更）まで進める．
- **データ：** MSCOCO val2017 のみ（ex017・ex019 と同じ dev 500枚，test 500枚）．
  - 細かい粒度の正解は，同じ画像の COCO のキャプションから作った．キャプションの名詞の WordNet の第1語義のうち，正解クラスの下位語になるものを用いる（例：person → man，woman，skier）．
  - θ_f と D は dev の hF で選び，test で報告した．
- **VG.pdf との関係：** VG.pdf の手法は用いていない．用いなかったものは，VG の頻度に基づく語彙，人手の最上位の枠と中間階層，上から下への木の命名，部分木の確率の合計，SigLIP である．VG.pdf からは，評価の考え方だけを参考にした．
  - 階層的適合率・再現率・F値（hP，hR，hF）
  - 正解ボックスによる，検出の影響を除いた評価
  - 粒度と正しさの交換
- **主な結論：**
  1. **細分化は現在の手順ではほとんど正しくならない．** 細かい正解を持つ test のインスタンス912件のうち，細分化した語が正解の経路上にある割合は2〜6%である．新しい提案手法（OWLv2@20）では3.2%であった．
  2. **最大の原因は，person の直下の下位語の多さである．** 細かい正解の85%は人物である．正解の経路を1段ずつ与えても，person の直下の398語の中から正しい子（adult，male など）を選べる割合は0.5%であった（Alpha-CLIP．正解の子の順位の中央値79位）．
  3. **正しい経路を与えれば，Alpha-CLIP は細分化の各段で最も正確な F である．**
     - 人物の2段目：Alpha-CLIP 0.268，CLIP-B/32 0.201
     - 人物の3段目：Alpha-CLIP 0.614，CLIP-B/32 0.414
     - 人物以外の1段目：Alpha-CLIP 0.570，CLIP-B/32 0.400
  4. **ただし，深さ0の人物の命名が細分化の前の段階で失敗する．** 正解ボックスでも，Alpha-CLIP は人物の78%に持ち物の名前を付けた（tennis racket，frisbee など）．検出から通すと，新しい提案手法では人物の88%が深さ0の棄却（joint の θ0）で残らない．
  5. **細分化の hF は，古い提案手法と YOLO11x + CLIP-B/32 が高い．** test の hF（dev で選んだ条件）は以下の通りである．
     - 古い提案手法：0.205
     - YOLO11x + CLIP-B/32：0.225
     - 新しい提案手法：0.100
     新しい提案手法と古い提案手法の差は −0.104（[−0.136, −0.069]，$`p = 0.001`$）である．
  6. **粒度を変えると，新しい提案手法では細分化した方が hF は上がる．** D = 0 の0.067から0.100になった（+0.034，$`p = 0.001`$）．一方，CLIP を用いる構成では，深さ1〜2で止めるのが最良である．葉まで細分化すると，D = 0 より hF が下がる．

## 2. 実験条件（`programs/ex020_coco_owl_alphaclip_granularity/`）

### 2.1 手法（order_029・order_030 の提案手法のまま）

1. **検出と深さ0：** ex019 の E2 で dev の F値で選んだ設定（予算と θ0）をそのまま用いた．検出と特徴は ex019 のキャッシュを再利用した．
2. **細分化：** 深さ0で選んだ語の Synset の直接の下位語を語彙とし，F の確信度（softmax）が最大の語を選ぶ処理を繰り返す（ex017 の `granular_annotation`）．
3. **粒度の変更：** 深さ1以降の確信度が θ_f 未満になるか，最大の深さ D に達した段階で止める．
   - θ_f ∈ {−∞, 0.05, 0.1, 0.2, …, 0.9, 0.95, 0.99}
   - D ∈ {0, 1, 2, 3, 4, 6, ∞}
   - この格子から dev の hF が最大の組を選んだ．
   - 葉まで求めた出力の列の先頭部分を取り出す処理と等しいため，出力の列は1回だけ計算した．

| 実験 | 内容 |
| :--- | :--- |
| E1_gt | 正解のボックスに対する細分化．F ∈ {CLIP-ViT-B/32，CLIP-ViT-B/16，Alpha-CLIP（context1.5）} |
| E2_pipeline | 検出から細分化まで．ex019 の6構成（古い提案手法，YOLO11x + CLIP-B/32，YOLO11x + Alpha-CLIP，OWLv2@20 + CLIP-B/32，新しい提案手法 OWLv2@10・@20 + Alpha-CLIP）．未検出・棄却されたインスタンスは出力なしとして hR に含める |
| E3_step | 正解のボックスで，正解の経路を1段ずつ与えた場合（教師強制）の各段の正解率と，正解の子の順位 |

### 2.2 細かい粒度の正解と評価指標

- **細かい正解：**
  1. spaCy でキャプションの名詞を取り出す．直前の語と合わせた複合語が WordNet にあれば，それを優先する．
  2. 名詞を WordNet の第1語義に変換する．
  3. 正解クラスの真の下位語を細かい正解とする．
  - キャプションはインスタンスと対応しない．そのため，同じ画像の同じクラスのインスタンスは，細かい正解の集合を共有させた．
- **正解の件数（test）：** 912件で，正解インスタンス全体3458件の26%にあたる．
  - クラス：person 777，cow 20，cup 14，book 13，car 12 など
  - 細かい正解：man.n.01 446，woman.n.01 206，child.n.01 100，tennis_player.n.01 80 など
- **階層的評価：**
  - G：クラスの Synset から細かい正解までの上位語の経路
  - P：出力の列の Synset
  - $`hP = \sum|P \cap G| / \sum|P|`$，$`hR = \sum|P \cap G| / \sum|G|`$，hF はその調和平均である．細かい正解が複数ある場合は，重なりが最大のものを用いた．
- **出力の内訳：**
  - 「細分化の正解率」：深さ1以上で G の上にある割合（細かい正解との完全一致を含む）
  - 「細分化の誤り」：深さ0は正しいが，細分化が経路を外れた割合
  - 「クラスの誤り」：深さ0が誤った割合
  - 「出力なし」：未検出または棄却された割合

### 3.4 粒度と正しさの交換

![θ_f を変えた場合の test の hR と hP（(a) 正解ボックス，(b) 検出から），(c) 最大の深さ D と hF（θ_f = −∞）．星は dev で選んだ条件](../outputs/ex020_coco_owl_alphaclip_granularity/fig_granularity_tradeoff.png)

- **CLIP を用いる構成：** θ_f を下げて深く細分化するほど，hP が大きく下がり，hR はわずかしか上がらない．深さ1〜2で止めるのが最良である．
- **OWLv2 の構成：** D = 0 から1にすると hF が上がる．D = 0 で残るボックスは人物以外が中心で，人物以外の細分化は比較的正しいためである．

## 5. 未解決の論点と次の候補

- **評価の限界：**
  - 細かい正解はキャプションから作ったため，インスタンスと対応しない．
  - 第1語義の誤りが混ざる（例："controller" → accountant．test で39件）．
  - 細かい正解の85%が人物であり，人物以外は135件しかない．
  - キャプションより細かい出力（例：man より下位の語）は，正しくても hP が下がる．
- **細分化の課題（VG.pdf の手法を用いない範囲の候補）：**
  1. 候補の多い段（person の398語）の扱い．
     - 候補案：WordNet の SemCor の頻度が0の語を除く．
     - 候補案：2〜3段下までの子孫をまとめて候補にし，選んだ語までの経路を出力する．
  2. 人物の深さ0の命名の改善．
     - 候補案：Alpha-CLIP の入力を crop にする（context1.5 は持ち物に引きずられる）．
     - 候補案：人物だけ OWLv2 のテキストクエリのスコアを併用する．
  3. 深さ0の棄却（joint の θ0）が人物を落とす問題（report_030 から継続）．
- **構成の選択：**
  - COCO の範囲の細分化の hF は，YOLO11x + CLIP-B/32 が最も高い．
  - 人物以外の細分化の正解率は，YOLO11x + Alpha-CLIP が最も高い．
  - 検出を YOLO11x，F を Alpha-CLIP（または深さで使い分ける）とする構成が，次の比較の候補である．
