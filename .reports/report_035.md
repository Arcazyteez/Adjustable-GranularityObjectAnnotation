# report_035：新しい提案手法（OWLv2 + Alpha-CLIP + WordNet）のこれまでの結果のまとめ（ex018〜ex021）

## 1. 概要

- **目的：** 新しい提案手法を検討し始めた ex018（report_028）から，棄却の判定の探索（ex021，report_033）と論文・スライド（report_034）までの結果をまとめる．特に，検出器の OWL と YOLO の比較，および命名の F の CLIP と Alpha-CLIP の比較を整理する．
- **新しい実験は行っていない．** 数値は全て outputs/ex018〜ex021 の CSV と report_028〜033 による．まとめの図は `programs/summary_new_method/make_summary.py` で CSV から作った．
- **データ：** ex018 は LVIS v1 val の474枚（COCO の物体と COCO 外の物体の両方の GT がある）．ex019〜ex021 は MSCOCO val2017 の dev 500枚・test 500枚で，条件は dev で選び test で報告した．
- **結論の要約：**
  1. **OWL と YOLO：**
     - OWLv2 の物体らしさは，YOLO が検出する物体をほぼ含み，YOLO が見逃す COCO 外の物体も検出できる．LVIS では，平均50個/枚で COCO の物体の97.5%，YOLO が見逃した COCO 外の物体の71.6%を検出した．
     - しかし，COCO の80クラスの評価では YOLO11x 単体が圧倒的に強い．F値は0.719で，最良の新しい提案手法は0.411である．速度も YOLO11x が約27倍速い（0.018秒/枚，新しい提案手法は約0.49秒/枚）．
     - OWLv2 の弱点は，人物の全体のボックスの物体らしさが低いことである．そのため，人物が棄却されやすい．
  2. **CLIP と Alpha-CLIP：**
     - Alpha-CLIP が有利なのは3つの場合である．正解ボックスと OWLv2 のボックスで深さ0の Top-1 が高い．細分化の各段の正解率が高い．部分木の確率の合計と組み合わせると，細かい粒度の hF が CLIP を上回る．
     - 一方，Alpha-CLIP は DETR・YOLO のボックスでは CLIP-ViT-B/32 に劣る．また，COCO の80クラスの softmax だけで命名すると，人物を持ち物の名前で呼ぶ．
     - Alpha-CLIP の利点は，部分木の確率の合計（mass）で棄却・命名する場合にはじめて検出から命名までの成績に現れた．
  3. **到達点：** 最良の新しい提案手法（OWLv2@50，Alpha-CLIP の crop，NMS + 包含，mass × 物体らしさ，mass ラベル）は，古い提案手法（DETR + CLIP-B/32）の F値を上回った（0.411 対 0.378，$`p = 0.018`$）．細かい粒度の hF は古い提案手法と同程度である（0.461 対 0.466）．YOLO11x 単体（F値 0.719，hF 0.670）との差は大きい．

## 4. CLIP と Alpha-CLIP の比較

![(a) 正解ボックス，DETR のボックス，OWLv2 のボックスでの深さ0の Top-1（ex019，test．検出のボックスは θ ありの joint），(b) 正解ボックスでの細かい粒度の hF（ex020，命名の手順ごと），(c) 正解ボックスで正解の経路を1段ずつ与えた場合の各段の Top-1（ex020）](../outputs/summary_new_method/fig_clip_alphaclip.png)

比べたのは CLIP-ViT-B/32（OpenAI，QuickGELU，ボックスの切り抜きを黒で正方形にパディング）と Alpha-CLIP-ViT-B/16（`clip_b16_grit+mim_fultune_4xe`）である．Alpha-CLIP の入力は，ボックスの長辺の1.5倍の窓とボックスの内側を1とするαマスク（context1.5）か，切り抜きを正方形にパディングした crop である．同じ ViT-B/16 の CLIP（CLIP-ViT-B/16）も ex019 で比べた．

### 4.1 深さ0（COCO の80クラス）の命名

| F | 正解ボックス Top-1 | Top-5 | DETR のボックス Top-1 / F値 | OWLv2 のボックス Top-1 / F値 | 1ボックスの時間 |
| :--- | ---: | ---: | :--- | :--- | ---: |
| CLIP-ViT-B/32 | 0.497 | 0.738 | **0.696 / 0.394** | 0.768 / 0.327 | **2.3 ms** |
| CLIP-ViT-B/16 | 0.484 | 0.735 | 0.682 / 0.382 | **0.808** / 0.335 | 3.7 ms |
| Alpha-CLIP（crop） | **0.527** | 0.766 | — | — | 3.8 ms |
| Alpha-CLIP（context1.5） | **0.527** | **0.817** | 0.650 / 0.357 | 0.802 / **0.340** | 4.8 ms |
| Alpha-CLIP（画像全体 + マスク） | 0.309 | 0.569 | — | — | 4.5 ms |

検出のボックスは ex019 の θ あり・joint の結果（OWLv2 は dev で選んだ10個/枚）である．

- **正解ボックス：** Alpha-CLIP は CLIP-B/32 より Top-1 が3.0ポイント高い（McNemar 検定 $`p = 0.0017`$）．同じ ViT-B/16 の CLIP との差は4.3ポイントである（$`p = 1.5 \times 10^{-6}`$）．周囲を含める context1.5 は Top-5 を大きく上げる．画像全体とマスクを与える入力は，小さい物体が数パッチしか占めないため大きく劣る．
- **検出のボックスでは検出器によって効果が逆になる．** OWLv2 のボックスでは，Alpha-CLIP の Top-1 は CLIP-B/32 より3.4ポイント高い（[0.010, 0.060]）．ただし F値の差 +0.013 は有意でない．DETR のボックスでは，Alpha-CLIP は Top-1 も F値も CLIP-B/32 より低い．
- **参考（ハイブリッド手法，report_030，現在の実験からは削除）：** YOLO11x のボックスでも同じ傾向であった．YOLO11x + CLIP-B/32 は F値 0.458（Top-1 0.669），YOLO11x + Alpha-CLIP は0.419（0.612）である．
- **人物の命名の失敗：** 細かい正解を持つインスタンス（85%が人物）に限ると，Alpha-CLIP（context1.5）は人物の多くに持ち物の名前（tennis racket，frisbee など）を付ける．report_031 では，人物の78%がこの失敗であった．ex020 の正解ボックスでの COCO の80クラスのみの命名の正解率は，CLIP-B/32 が0.518，Alpha-CLIP が0.307である．

### 4.3 検出から命名まで（ex021）

- **Alpha-CLIP の入力：** 最良の条件で crop を context1.5 にすると，F値は0.411から0.365に，人物の再現率は0.545から0.475に下がる．context1.5 は周囲の物体（持ち物）に引きずられやすい．ex019 の正解ボックスでは2つの入力の Top-1 は同じ（0.527）であったが，mass による棄却・命名では crop が良い．
- **mass との組み合わせ：** 棄却のスコアを joint（COCO の softmax の最大値 × 物体らしさ）から mass × 物体らしさにすると，F値は0.293から0.411に上がる（最良の条件から1要因だけ変えた比較）．Alpha-CLIP の確率を部分木で集約することで，人物が残り，person と命名される（0.001 → 0.533）．
- **未実施の比較：** ex021 の最良の条件で F を CLIP-B/32 に替えた比較（OWLv2 + CLIP-B/32 + mass）は行っていない．そのため，最良の条件での Alpha-CLIP の効果は直接は測れていない．Old（DETR + CLIP-B/32）に mass ラベルだけを加えた条件は F値 0.369（Old は0.378）で，効果が小さかった．

## 5. 考察

- **New の改善の大部分は，棄却と深さ0のラベルの変更による．** 検出器と F の性能そのものは，正解ボックスと検出の再現率でほぼ決まっていた．しかし，COCO の80クラスの softmax の最大値を棄却と命名に使う限り，OWLv2 と Alpha-CLIP の組み合わせは人物を落とした．部分木の確率の合計で集約すると，この問題が解消した．
- **OWLv2 と Alpha-CLIP は相性が良い．** Alpha-CLIP の効果は OWLv2 のボックスでのみ現れ，DETR・YOLO のボックスでは逆になった．OWLv2 のボックスは物体によく合い，部分や COCO 外の物体を含む．αマスクで注目領域を指定する Alpha-CLIP は，こうした多様な領域の命名に向く可能性がある．ただし，これは観測された傾向であり，原因は検証していない．
- **YOLO11x との差は評価の範囲に由来する部分がある．** COCO の80クラスと，85%が人物のキャプションによる細かい正解では，閉じた語彙の YOLO11x が有利である．New の利点（COCO 外の物体の検出，COCO のクラスより細かい語）は，ex018 の LVIS の確認と出力例でしか示せていない．

## 7. 未解決の論点と次の候補

- **COCO 外の物体の評価：** OWLv2 の利点を測るには，LVIS や VG の注釈で検出から命名まで評価する必要がある．ex018 は領域の確認だけで，命名は評価していない．

- **選択の偏り：** 最良の条件は120通りから選んだ．Old との F値の差（$`p = 0.018`$）は大きくなく，別の分割での確認が望ましい．
