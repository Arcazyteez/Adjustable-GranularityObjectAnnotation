# report_047：発表の台本を発表者ノートに追加

## 1. 実施内容
order_045 の発表の台本を，`slides_2026C.pptx`（16枚）の各スライドの発表者ノートに入れた．
- 台本は，order_046 で簡単にしたスライドの言い方と数値に合わせて直した．
- スライドの見た目は変えていない．論文は変更していない．

| 台本の修正点 | 内容 |
| :--- | :--- |
| 例 | 背景の例を，スライドと同じ person → skater → skateboarder にした |
| 7枚目 | 数値（50%，15%，8%，35%）は「説明のための例」と最初に断るようにした |
| 12枚目 | OWLv2 の値は，表に合わせて具体的な数値を言わず「80種類の物はどれもある程度見つけられる」とした |
| 13枚目 | 「73%が10%に落ちる」と，スライドの数値に合わせた |
| 16枚目 | 最後に「ご清聴ありがとうございました」を加えた |

## 2. 各スライドのノートの長さ
| 枚 | 文字数 | 枚 | 文字数 |
| ---: | ---: | ---: | ---: |
| 1 | 107 | 9 | 239 |
| 2 | 204 | 10 | 163 |
| 3 | 230 | 11 | 170 |
| 4 | 235 | 12 | 154 |
| 5 | 120 | 13 | 169 |
| 6 | 119 | 14 | 82 |
| 7 | 369 | 15 | 98 |
| 8 | 191 | 16 | 210 |

- 合計は約2,860文字である．1分に約300文字で話すと，およそ10分になる．
- 7枚目（細かさの決め方）が最も長い．研究の中心であるためである．

## 3. 実装
- `slides/build_slides_2026C.py` に次を加えた．ビルドの最後に `add_notes()` を呼ぶ．
  - `NOTES`：16枚分の台本．
  - `notes_xml()`：ノートのページのXMLを作る．
  - `slide_order()`：スライドの表示順を求める．
  - `add_notes()`：作成済みの pptx に，テンプレートのノートのマスターを用いてノートのページを書き込む．
- テスト：`tests/test_slides_notes.py`（2件）を追加した．既存のテストと合わせて6件が通った．

## 4. 確認
- python-pptx で `slides_2026C.pptx` を読み込み，16枚全てのノートに台本が入っていることを確認した．
- pptx-render で `slides_2026C.pdf`（16枚）を作成でき，スライドの表示は order_046 と変わらない．
- pptx の ZIP に破損と重複がないことを確認した．
- PowerPoint の実機では開いていない．ノートの表示は，PowerPoint の「ノート」表示で確認してほしい．

## 5. 未解決の論点
- 台本は聴衆を一般向けと想定した言い方である．研究者向けの場合は，用語を戻す必要がある．
