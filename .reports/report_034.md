# report_034：新しい提案手法の結果の論文とスライドの作成

## 1. 概要

- **目的：** report_033（ex021）を中心に，新しい提案手法（OWLv2 + Alpha-CLIP + WordNet）の結果を論文と発表スライドにまとめる．
- **対象の仮定：** 投稿先・ページ数・発表時間の指定が無いため，以下を仮定した．
  - 論文：VG.pdf（著者らの先行研究）と同じ ieicejsp の和文2段組で約6ページ
  - スライド：研究室の進捗報告など，約12〜15分の研究発表
- **比較：** order_032 の3手法（New，Old，YOLO11x 単体）とした．ハイブリッド手法は載せず，SigLIP は使っていない．

## 2. 論文（`paper_2026C/main.pdf`，6ページ）

- **題目：** 開放語彙の物体らしさと注目領域付きCLIPによる粒度可変物体アノテーションにおける棄却の判定
- **構成：**

| 章 | 内容 |
| :--- | :--- |
| 1 はじめに | 新しい構成が人物を棄却する問題と，貢献3点 |
| 2 関連研究 | 物体検出とオープンボキャブラリ（YOLO，DETR，CLIP，OWL-ViT，OWLv2，Alpha-CLIP），語彙と意味の階層（VG，前稿，CHiLS，階層的評価） |
| 3 提案手法 | 図1（流れ），式(1)語の確率，式(2)VG の語彙，式(3)部分木の確率の合計，式(4)棄却のスコアと深さ0のラベル，包含の除去，式(5)命名と粒度の変更 |
| 4 実験 | 共通設定（式(6) hP・hR），検出器の再現率，棄却の判定（表1 主要な比較，表2 要因の効果，図2），粒度の判断（表3 命名の手順，図3 各段の正解率），定性評価（図4） |
| 5 考察 | 部分木の確率の合計による棄却，評価指標の選択（hF は誤検出で下がらない），本稿の限界 |
| 6 おわりに | まとめと今後の課題 |

- **図の作成：** `paper_2026C/make_figures.py` で outputs/ex020・ex021 から作成した．
  - `fig_rejection`：棄却のスコアごとの F値，120通りの適合率と人物の再現率
  - `fig_step`：WordNet の木と VG の木の各段の正解率
  - `fig_qualitative`：ex021 のキャッシュから描き直した比較画像
- **引用：** VG.pdf を前稿（ref_prevVG）として，これまでの和文論文（paper の題目）を ref_prev として引用した．著者名と発表先は仮置き（「著者名」，2026）である．
- **数値：** 全て report_033・report_032 の値（test，θ は dev の F値で選択）と一致させた．
  - 主結果：F値は 0.326 から 0.411 になり，Old は 0.378，YOLO11x は 0.719 である．
  - 人物の再現率：0.108 から 0.545
  - hF：0.255 から 0.461
- **コンパイル：** latexmk で Overfull と未定義の参照が無いことを確認した．

## 5. 未解決の論点

- **著者名・所属・発表先：** 未定で，仮置きである．投稿先が決まれば，ページ数と様式を合わせる必要がある．
- **論文の評価の範囲：** COCO の80クラスとキャプションの細かい正解（85%が人物）に限られる．COCO 外の物体の評価が無いことを「本稿の限界」に明記した．
- **最上位の枠：** 著者が定めた40個であり，VG.pdf の枠とは一致しない．論文にも明記した．
- **Old との差：** $`p = 0.018`$ で，120通りから選んだ条件による．別の分割での確認が今後の課題である．
- **スライドの比較画像（14枚目）：** ラベルの文字が小さい（論文の図の流用）．発表に使う場合は，画像を2枚程度に絞って拡大する案がある．
