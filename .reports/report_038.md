# report_038：YOLO11x と DETR の検出の比較（ex022）

## 1. 概要

- **目的：** ex018 の比較画像 `fig_examples_gain.png`（YOLO11x と OWLv2）と同じ形式で，YOLO11x と DETR の検出を比べる．
- **データ：** COCO val2017 の test 500枚（ex017 と同じ分割，seed 42），正解3458件（人物1090件，人物以外2368件）を用いた．検出結果は ex017 で保存したもの（`datasets/ex017_coco_granular_annotation/detections_{YOLO11x,DETR}_test.pt`）を読み，新しく検出器は動かしていない．これは ex019〜ex021 で用いた検出結果と同一である．
- **条件：** YOLO11x は conf 0.25 以上，DETR はスコア 0.5 以上のボックスを用いた．クラスを問わず，IoU 0.5 以上で重なるボックスがあれば正解を「検出できた」とした（ex017 の E2 と同じ定義）．
- **プログラム：** `programs/ex022_yolo_detr_region_check/train.py`．テストは `tests/test_ex022_yolo_detr.py`（3件，全て成功）．

## 2. 結果

### 2.1 検出器ごとの性能（`table_detector.csv`）

| 検出器 | 閾値 | ボックス数/枚 | 再現率 | 正解に当たらないボックスの割合 |
| :--- | ---: | ---: | ---: | ---: |
| YOLO11x | 0.25 | 6.2 | 0.702 | 0.201 |
| DETR | 0.5 | 11.2 | 0.738 | 0.475 |

再現率は ex017 の E2（0.702，0.738）と ex019 の `recall_person_test.csv`（人物 0.800，0.828）に一致した．

### 2.2 正解の内訳（`table_gt_status.csv`，`fig_gt_status.png`）

| 区分 | 件数 | 両方が検出 | YOLO だけ | DETR だけ | 両方が見逃し |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 人物 | 1090 | 0.762 | 0.038 | 0.065 | 0.135 |
| 人物以外 | 2368 | 0.597 | 0.060 | 0.101 | 0.243 |
| 全体 | 3458 | 0.649 | 0.053 | 0.089 | 0.209 |

![正解の内訳](../outputs/ex022_yolo_detr_region_check/fig_gt_status.png)

正解の約65%は両方の検出器が検出しており，一方だけが検出した正解は合計で約14%（YOLO だけ 5.3%，DETR だけ 8.9%）である．DETR の再現率が3.6ポイント高いのは，DETR だけが検出した正解が YOLO だけの正解より多いためである．一方，DETR のボックスの47.5%は正解に当たらず，YOLO の20.1%の約2.4倍である．DETR はボックスを約1.8倍出すことで，わずかに再現率を得ている．両方が見逃す正解は全体の約21%あり，人物以外では24%に達する．

## 3. 考察

- 検出の性能として，YOLO11x と DETR は同程度である．両者の差（再現率で3.6ポイント）は，DETR がボックスを多く出すことによるものであり，正解に当たらないボックスも多い．
- ex021 での YOLO11x 単体（F値 0.719）と Old（DETR + CLIP，F値 0.378）の差は，本実験の検出の差（約0.04）では説明できず，命名の段階の差である．
- 両方の検出器が見逃す正解（21%）は，小さく密集した物体が中心である．ex019 の OWLv2@50 は再現率 0.875 であり，この見逃しを補う役割を持つ．

## 5. 未解決の論点

- **ボックス数をそろえた比較：** 本実験は各検出器の既定の閾値で比べた．COCO の test でボックス数をそろえた比較（ex010 の LVIS の曲線に相当）は行っていない．
- **OWLv2 を加えた3者の比較：** 同じ画像で OWLv2@20，@50 を並べた比較画像は作っていない（ex019 の検出結果 `detections_OWLv2_test.pt` で作成できる）．
- **画像の選び方：** 比較画像は一方だけが検出した正解の数で選んでおり，代表的な画像ではない．
