# report_006：YOLOとCLIPを組み合わせたハイブリッド構成の実装と論文への追記

## 1. 概要

深さ0のカテゴリをYOLO11xの予測とし，深さ1以降の細分化のみをCLIP-ViT-B/32とWordNetで行うハイブリッド構成を実装した（ex006）．
COCO外の物体に対しては，CLIPがCOCOの80クラスとCOCO外の22語の中でCOCO外の語を最上位に選んだ場合に，深さ0をCLIPの語へ切り替える規則も評価した．
結果を論文 `paper/main.pdf` の4.9節として追記し，概要，はじめに，考察，おわりにの関連箇所も修正した．
規約に従い，order_003で赤字にした箇所を黒字に戻した上で，今回の修正箇所のみを赤字にした．

| 項目 | 主な結果 |
| :--- | :--- |
| 深さ0のTop-1正解率 | 切替なしで0.981〜0.993（YOLO11xと同じ）．提案手法は0.560〜0.604 |
| 階層アノテーションの対象数 $` N_h `$ | 閾値0.25で2167件．提案手法の $` \theta = 0.5 `$ の1313件の1.65倍， $` \theta = 0.97 `$ の917件の2.36倍 |
| 深さ1の推定の一致率 | 提案手法（ $` \theta = 0.97 `$ ）と共通の761件で0.775．同じCLIPを用いるため，不一致はボックスの違いによる |
| 切替（ $` \gamma = 0 `$ ） | COCOの500枚で47件が切り替わり，すべてYOLOが正解していたインスタンスであった（Top-1は0.981から0.959に低下） |
| 切替（ $` \gamma = 0.5 `$ ） | COCOの500枚では切替が0件で，切替なしと同一．COCO外の実画像では penguin，helicopter，camel，kangaroo に正しく切り替わった |

## 2. 手法

YOLO11xが出力した領域 $` k `$ のボックスを $` {\mathbf b}_k `$ ，クラスを $` y_k `$ とする．
COCO外の22語の集合を $` {\mathbb V}_E `$ ，102語の候補語彙 $` {\mathbb V}^{(0)} \cup {\mathbb V}_E `$ に対するCLIPの推定単語を $` u_k `$ とし，深さ0の単語を次のように決める．

```math
\hat{v}_k^{(0)} =
\begin{cases}
    u_k & (u_k \in {\mathbb V}_E \ \text{かつ}\ f({\mathbf X}_k; {\mathbb V}^{(0)} \cup {\mathbb V}_E)_{u_k} \geq \gamma) \\
    y_k & (\text{それ以外})
\end{cases}
```

ここで， $` f `$ はCLIP-ViT-B/32， $` {\mathbf X}_k `$ はYOLOのボックスを切り出してpadで正方形にしたクロップ， $` \gamma `$ は切替に必要な確信度の下限である．
深さ1以降は，提案手法と同じ `hierarchical_annotation`（論文の式(3)）でWordNetの下位語をたどる．

| 構成名（`outputs/` の手法名） | 深さ0の決定 |
| :--- | :--- |
| `hybrid` | 常にYOLOのクラス |
| `hybrid_switch` | $` \gamma = 0 `$ で切替 |
| `hybrid_switch_c0.5` | $` \gamma = 0.5 `$ で切替（1回目の実行結果を確認した後に追加した） |

## 3. 実験条件

`programs/ex006_coco_val500_yolo_clip_hybrid/`，結果は `outputs/ex006_coco_val500_yolo_clip_hybrid/` に保存した．

| 項目 | 設定 |
| :--- | :--- |
| 評価画像 | ex003，ex005と同じseed=42の500枚（GTインスタンス3206件） |
| YOLO | YOLO11x（検出スコアの閾値0.25，0.5，0.7）．ex005の `instances.json`（GTとの対応付け済み）を再利用した |
| VLM | CLIP-ViT-B/32，プロンプト "a photo of a {}"，pad |

### 4.2 COCO外の語への切替

$` \gamma = 0 `$ では，切り替わった47件（閾値0.25）はすべてYOLOが正解していたインスタンスであった．
主な内訳は，sheep → camel（8件），person → dolphin，monkey，penguin（各3件）等である．
bird → eagle（1件）のように，切替先がGTカテゴリの下位語である場合も不正解として数えている．
$` \gamma = 0.5 `$ では，COCOの500枚のいずれの閾値でも切替は生じなかった．

## 6. 考察

ハイブリッド構成は，検出とカテゴリのアノテーションを分離した設計により，深さ0のみをYOLOに置き換えられることを示している．
深さ0の精度はYOLOと同じになり，深さ0の誤りによって誤った分岐をたどるインスタンスが減るため，粒度可変のアノテーションを付与できるGTインスタンスが大幅に増えた．
一方，深さ1の推定はボックスの違いだけで約2割が変化しており，細かい粒度の推定はクロップに敏感である．
COCO外の語への切替は， $` \gamma = 0 `$ ではCOCOの物体を誤って切り替えるため有害であり，確信度の下限が必要である．
ただし， $` \gamma = 0.5 `$ は同じ500枚の結果を見て選んだ値であり，COCO外の物体の評価も6枚の定性評価にとどまる．

## 7. 未解決の論点と次に検討すべき作業の候補

1. **切替の閾値 $` \gamma `$ の検証**： $` \gamma = 0.5 `$ は評価に用いた500枚の結果を見て追加した．COCOの別の画像（val2017の残り4500枚）で切替が生じないか，COCO外のカテゴリを含むデータセット（LVIS等）で切替が正しく働くかを検証する必要がある．
2. **深さ1以降の正誤評価**：COCOには細かい粒度の正解がないため，ハイブリッド構成と提案手法の深さ1以降の優劣は評価していない．Stanford Dogs，CUB-200，LVIS等で評価できる．
3. **人物クラスの細分化**：ハイブリッド構成では人物の深さ1の平均確信度が0.080と低く，`person.n.01` の下位語（平均398語）は外見で判断できない語を多く含む．WordNet階層の選別（チャットでの提案4）と組み合わせることが考えられる．
4. **単一候補の分岐**：giraffe → okapi のような分岐は深さ0の推定を変えても解消されない（深さ1以降の段階の15.0%）．
5. **スライドへの反映**：`slides_object_annotation.pptx` にはハイブリッド構成を反映していない．
6. **ai-agentによる検証**：`tokens.json` が存在しないため，AIエージェントによる論文の検証は実行していない．
