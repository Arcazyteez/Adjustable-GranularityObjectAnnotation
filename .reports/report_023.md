# report_023：出力例の図に各単語の確信度を表示

## 1. 概要

論文とスライドの出力例の図では，これまで各ボックスに「出力した単語とアノテーションのスコア s」を1つ表示していた．今回，経路上の全ての単語と，その確信度を表示するようにした．

- **新しい実験：** 行っていない．既存の出力を使った．
  - 提案手法：`outputs/ex015a_annotation_score/qualitative/{st,ens}.json`
  - 予備実験：`outputs/ex012_wordnet_granular_annotation/qualitative_yolo_{CLIP,SigLIP}/test/42/annotations.json`
- **表示する2種類の確信度：**

| 記号 | 式 | 意味 |
| :--- | :--- | :--- |
| s | 式(9)（スライドでは式(4)） | アノテーション全体が正しい確率．領域が物体であることも含む |
| r | 式(10)（スライドでは式(5)） | 領域が物体である場合に，経路上のその単語が正しい確率．粗い語から細かい語へ単調に下がる |

## 2. 論文（`paper_2026B/main.pdf`，10ページ）

- **赤字の扱い：** order_022の赤字を黒字に戻し，今回の修正を赤字にした．
- **図5（提案手法の出力例，`make_figures.fig_qualitative_open`）：**
  - 各ボックスに番号，出力した単語，s を表示した．

  - 全ての経路に共通する object と whole は省略した．
  - 一覧を読める分量にし，10ページに収めるため，加えた領域を画像ごとに上位8件から上位3件に減らした．

  - この手法には確率のスコアが無い．そのため，各単語と切り抜き画像のコサイン類似度を一覧に示した．
  - 類似度は確率ではなく，同じ段階の候補の間の大小のみに意味を持つことを図の説明に明記した．

  - ski boot は r が0.89であるのに対し，s は0.54である．両者の差は，領域が物体の全体であるかの不確かさを表す．

## 5. 未解決の論点と次の候補

- **YOLO11xのボックスの確信度：** YOLO11xのボックスはクラスの1語のみで，経路上の単語の r は無い．クラスより粗い語の確信度を示すには，YOLO11xのボックスにも経路を求める必要がある．
- **表示する件数：** 論文のページ数の制限のため，加えた領域を画像ごとに3件に減らした．8件の一覧が必要な場合は付録に回せる．
- **予備実験の確信度：** 予備実験の手法には確率が無いため，類似度で代えた．同じ段階の候補でソフトマックスをとれば確率にできるが，候補ごとの類似度を保存していないため，再計算が必要である．
- **ai-agent による検証：** `tokens.json` が無いため，行っていない．
