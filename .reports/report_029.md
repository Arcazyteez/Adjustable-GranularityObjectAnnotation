# report_029：新しい提案手法（OWLv2 + Alpha-CLIP + WordNet）と古い提案手法の比較（ex019）

## 1. 概要

- **目的：** 新しい提案手法（OWLv2 の物体らしさ → Alpha-CLIP → WordNet）と古い提案手法（DETR → CLIP-ViT-B/32 → WordNet）の性能と処理速度を，MSCOCO val2017 のみで比較する．
- **データ：** ex017 と同じ dev 500枚と test 500枚である．ボックス数・$`\theta`$・Alpha-CLIP の入力は dev で選び，test で報告する．
- **主な結論：**
  1. **ラベルの正確さは新しい提案手法が上．** 対応したボックスの Top-1 正解率（$`\theta`$ あり）は 0.680 から 0.802 に向上した（差 +0.122，95%信頼区間 [0.090, 0.154]，$`p < 0.001`$）．正解ボックスに対する命名でも，Alpha-CLIP は CLIP-ViT-B/32 を上回った（0.527 対 0.497，McNemar 検定 $`p = 0.0017`$）．
  2. **COCO の F値は古い提案手法が上．** F値は 0.378 から 0.340 に下がった（差 −0.038，[−0.066, −0.010]，$`p = 0.008`$）．適合率は 0.388 から 0.405 に上がったが，再現率が 0.369 から 0.293 に下がった．
  3. **再現率が下がる原因は人物の検出．** OWLv2 の物体らしさは人物全体を囲むボックスを出しにくく，服や顔などの部分を囲む．平均10個/枚では，人物の正解のうち検出できたのは25.1%である（DETR は82.8%）．人物以外の正解では，平均20個/枚で DETR を上回った（0.774 対 0.697）．COCO の評価では，OWLv2 が囲んだ COCO 外の物体や物体の部分は誤検出と数えられる．そのため，dev の F値で選ぶボックス数は10個/枚と少なくなった．
  4. **処理速度は古い提案手法が約3倍速い．** 1枚あたり0.10秒に対し，新しい提案手法は0.31秒である．差の大部分は検出（DETR 0.05秒，OWLv2 0.23秒）による．
  5. **ex017 の不具合：** ex017 の CLIP は，open_clip の設定の都合で活性化関数が学習時と異なっていた（QuickGELU ではなく GELU）．本実験では修正した．ただし，正解ボックスでの Top-1 の差は小さく有意でない（0.493 対 0.497，$`p = 0.49`$）．

## 2. 手法と実験設定（`programs/ex019_coco_owl_alphaclip_wordnet/`）

| 構成要素 | 古い提案手法 | 新しい提案手法 |
| :--- | :--- | :--- |
| 検出器 D | DETR（ResNet-50，閾値0.5，平均11.2個/枚） | OWLv2（B/16 ensemble）の物体らしさ．平均ボックス数 {5, 10, 20, 30, 50} 個/枚になる閾値を dev のスコアで決め，dev の F値で選ぶ（10個/枚，閾値0.226） |
| 命名 F | CLIP-ViT-B/32（OpenAI，QuickGELU）．ボックスにちょうど合わせた切り抜き画像を黒で正方形にパディングする | Alpha-CLIP-ViT-B/16（`clip_b16_grit+mim_fultune_4xe`）．ボックスの長辺の1.5倍の正方形の窓と，ボックスの内側を1とするαマスク（dev で4種類の入力から選んだ） |
| 確信度 | COCO の80クラス内のソフトマックスの最大値 | 同じ．棄却には検出スコアとの積（joint）も比較し，dev の F値で joint を選んだ |
| 細分化 | WordNet の直接の下位語へ進む（ex017 の `granular_annotation`） | 同じ |

- **Alpha-CLIP の実装：** 公式の実装はパッケージの導入が必要である．そこで，open_clip の CLIP ViT-B/16（OpenAI，QuickGELU）のパッチ埋め込みに，αチャネル用の畳み込み `conv1_alpha` を加えた．公式の画像エンコーダの重みを strict に読み込んで，同じ計算を行う．文章エンコーダは元の CLIP のものである．αは公式と同じく $`(\alpha - 0.5)/0.26`$ で正規化した．
- **評価指標：** ex017 の E3 と同じである．クラスを問わず IoU 0.5 以上で対応したボックスの Top-1/Top-5 正解率，クラスを含めた適合率・再現率・F値を求めた．$`\theta`$ の候補は $`-\infty`$ と dev のスコアの分位点で，dev の F値で選んだ．
- **差の検定：** 古い提案手法と新しい提案手法の差は，test の画像単位の対応のあるブートストラップ（1000回）で求めた．
- **要素の切り分け：** D {DETR, OWLv2} × F {CLIP-ViT-B/32, CLIP-ViT-B/16, Alpha-CLIP} × 棄却のスコア {VLM, joint} の全ての組み合わせを評価した．

## 3. 結果

### 3.1 E1：正解ボックスに対する命名（COCO の80クラス）

| F（入力） | dev Top-1 | test Top-1 | test Top-5 | 1ボックスあたりの時間 |
| :--- | ---: | ---: | ---: | ---: |
| CLIP-ViT-B/32（GELU，ex017 の設定） | 0.478 | 0.493 | 0.749 | 2.1 ms |
| CLIP-ViT-B/32（古い提案手法） | 0.493 | 0.497 | 0.738 | 2.3 ms |
| CLIP-ViT-B/16 | 0.494 | 0.484 | 0.735 | 3.7 ms |
| Alpha-CLIP（crop） | 0.522 | **0.527** | 0.766 | 3.8 ms |
| Alpha-CLIP（context1.5，選択） | **0.530** | **0.527** | **0.817** | 4.8 ms |
| Alpha-CLIP（context2） | 0.519 | 0.515 | 0.802 | 4.7 ms |
| Alpha-CLIP（full：画像全体 + マスク） | 0.284 | 0.309 | 0.569 | 4.5 ms |

Alpha-CLIP は，同じ ViT-B/16 の CLIP より Top-1 が4.3ポイント高い（$`p = 1.5 \times 10^{-6}`$）．周囲を1.5倍まで含めると，Top-5 が大きく上がる．一方，画像全体とマスクを与える入力（公式の参照表現理解の評価と同じ形式）は大きく劣る．COCO の物体の多くは小さく，224×224 に縮小した画像全体ではボックスが数パッチしか占めないためである．

### 3.2 E2：検出から命名まで（test，θ あり）

| D | F | 棄却 | ボックス数 → 残した数 | Top-1 | 適合率 | 再現率 | F値 |
| :--- | :--- | :--- | ---: | ---: | ---: | ---: | ---: |
| **DETR** | **CLIP-B/32** | **VLM（古い提案手法）** | 11.2 → 6.6 | 0.680 | 0.388 | 0.369 | 0.378 |
| DETR | CLIP-B/32 | joint | 11.2 → 5.5 | 0.696 | 0.445 | 0.354 | **0.394** |
| DETR | CLIP-B/16 | joint | 11.2 → 5.5 | 0.682 | 0.430 | 0.344 | 0.382 |
| DETR | Alpha-CLIP | joint | 11.2 → 6.0 | 0.650 | 0.383 | 0.334 | 0.357 |
| OWLv2 | CLIP-B/32 | joint | 9.3 → 4.0 | 0.768 | 0.448 | 0.258 | 0.327 |
| OWLv2 | CLIP-B/16 | joint | 9.3 → 4.1 | **0.808** | **0.453** | 0.266 | 0.335 |
| **OWLv2** | **Alpha-CLIP** | **joint（新しい提案手法）** | 9.3 → 5.0 | 0.802 | 0.405 | 0.293 | 0.340 |

$`\theta`$ なしの場合（DETR は全てのボックス，OWLv2 は dev で選んだ5個/枚）の F値は，古い提案手法が0.333，新しい提案手法が0.319で，差は有意でない（$`p = 0.33`$）．

| 新しい提案手法との比較（θ あり，joint） | Top-1 の差 [95%CI] | F値の差 [95%CI] |
| :--- | :--- | :--- |
| 古い提案手法（DETR + CLIP-B/32） | +0.122 [0.090, 0.154] | −0.038 [−0.066, −0.010] |
| DETR + Alpha-CLIP（検出器だけを変えた効果） | +0.152 [0.122, 0.182] | −0.017 [−0.041, 0.006] |
| OWLv2 + CLIP-B/32（命名だけを変えた効果） | +0.034 [0.010, 0.060] | +0.013 [−0.006, 0.032] |

- **Top-1 の向上は主に OWLv2 による．** OWLv2 のボックスは物体によく合う（対応したボックスの平均 IoU は0.864，DETR は0.839）．さらに，確信度の高い物体だけが残る．ただし，対応するGTの集合が手法ごとに異なるため，Top-1 は「残ったボックスの正確さ」である．
- **Alpha-CLIP の効果は OWLv2 のボックスでのみ現れた．** OWLv2 のボックスでは CLIP-B/32 より Top-1 が3.4ポイント高いが，DETR のボックスでは逆に下がった．
- **COCO の再現率（クラス非依存，IoU 0.5）：** DETR は0.738である．OWLv2 は 5 / 10 / 20 / 30 / 50 個/枚 で 0.348 / 0.522 / 0.700 / 0.804 / 0.875 だった．OWLv2 は20〜30個/枚で DETR と同程度になる．しかし，このとき増えたボックスの多くは COCO 外の物体や部分であり，COCO の80クラスの名前が付いて誤検出となる．そのため，F値の最適は10個/枚になった．

| 正解のクラス | DETR | OWLv2 10個/枚 | OWLv2 20個/枚 |
| :--- | ---: | ---: | ---: |
| 人物（1090件） | 0.828 | 0.251 | 0.541 |
| 人物以外（2368件） | 0.697 | 0.647 | 0.774 |

### 3.3 E3：処理速度（test の100枚，RTX 4070 Ti，WordNet の細分化を含む）

| 手法 | 検出 | アノテーション | 合計 | ボックス数 → 残した数 | ピーク VRAM |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 古い提案手法 | 0.051 秒 | 0.047 秒 | **0.098 秒** | 11.0 → 6.9 | 3.2 GB |
| 新しい提案手法 | 0.231 秒 | 0.079 秒 | 0.310 秒 | 12.3 → 7.1 | 3.2 GB |

語彙を変えて再アノテーションする場合，検出は再実行しない．そのため，時間はアノテーションの部分だけ（0.047 秒対 0.079 秒）になる．

### 3.4 E4：深さごとの確信度と比較画像

深さ0が正しいインスタンスの平均確信度は，深さ0で 0.724 → 0.821，深さ1で 0.463 → 0.549 と，新しい提案手法が高かった．ただし，深さ1の平均候補数が異なる（118語対8.9語）．これは，新しい提案手法では候補の多い person の正解が少ないためである．同じ条件の比較ではない．COCO には深さ1以降の正解が無いため，細分化の正しさは評価していない．

![test の6枚に対する古い提案手法（左）と新しい提案手法（右）のアノテーション（深さ0〜2の語と確信度）](../outputs/ex019_coco_owl_alphaclip_wordnet/E4_depth/fig_comparison.png)

比較画像では，新しい提案手法の誤った名前（例：人物に付いた hair drier や pizza）は少ない．一方で，人物を検出しない画像が多い（3枚目，5枚目）．バナナの房のように1つの物体を部分ごとに囲む重複も見られる．

## 5. 未解決の論点と次の候補

- **人物の見逃しへの対策：** OWLv2 の物体らしさと，テキストクエリ「person」のスコアを併用する．または，ボックス数を画像ごとに上位K件とする．これで人物の再現率が DETR に近づけば，新しい提案手法の F値は古い提案手法を上回る可能性がある．
- **部分と全体の重複：** OWLv2 は物体全体と部分を両方囲む．COCO の評価では重複は誤検出だが，粒度可変アノテーションでは部分の命名に使える．クラス非依存の NMS の IoU を下げる，または包含関係で統合することを検討する．
- **評価の限界：** MSCOCO のみの評価では，OWLv2 が COCO 外の物体を検出する利点（ex018）が誤検出として数えられる．細分化（深さ1以降）の正しさも測れない．COCO の範囲で精度を上げるか，COCO のキャプションなどで細かい粒度を評価するかを決める必要がある．
- **Alpha-CLIP の入力：** マスクは矩形である．分割モデル（SAM 等）のマスクを用いると，公式の想定に近くなる．ViT-L/14 の重みも試していない．
