# report_004：研究発表スライドの作成

## 1. 概要

order_001〜003の研究内容と `paper/main.pdf` をもとに，研究発表用のスライド `slides_object_annotation.pptx`（18枚）を作成した．
スタイル確認用のPDF `slides_object_annotation.pdf` を `.ai/pptx-render` で生成し，リポジトリ内に保持している．

| 項目 | 内容 |
| :--- | :--- |
| 想定 | 研究室・学会での口頭発表，約15分（発表時間・聴衆の指定はなかったため想定） |
| テンプレート | `.ai/ai-pptx-kit/templates/research.pptx`（デザインは変更していない） |
| 生成方法 | `slides/build_slides.py` がテンプレートを展開し，pptxスキルの `add_slide.py` / `clean.py` でスライドを登録した上でOOXMLを直接書き込む．LibreOfficeは使用していない |
| 数式 | LaTeX → pandoc（docx経由）→ OMML．PowerPointのネイティブ数式（`a14:m`）として16個挿入．変数は数学用英数字（斜体・太字・白抜き）で表した |
| 検証 | pptxスキルの `validate.py --original`（テンプレート基準）で全項目合格．`pptx-render` によるPDFで全18枚を目視確認 |

## 3. 規約への対応

- 文字サイズは本文28pt，注釈24pt，図表20pt，引用12pt（テンプレートの引用の記法に合わせた）とした．
- 箇条書きは「・」，番号は「1.」の文字で記述し，PowerPointの箇条書き機能は使っていない．
- 式番号はテキストボックスで式の右側に配置し，式中の変数を説明した．
- 引用文献はテンプレートの「引用の記法」に従ってスライド下部に記載した．
- 初回のレンダリングで，タイトルのはみ出し，単語の途中での改行，引用と図形・表の重なり，上付き文字の欠落，キャプションのはみ出しを確認し，修正した．

## 4. 未解決の論点と次に検討すべき作業の候補

1. **発表時間と聴衆**：指定がなかったため約15分を想定した．時間が異なる場合は，実験2（11枚目）や定性結果（15枚目）を統合・削除して調整する．
2. **著者名・所属**：タイトルスライドはプレースホルダのままである．
3. **PowerPointでの表示確認**：確認は `pptx-render` によるPDFで行った．フォント（BIZ UDGothic）や数式の最終的な表示は，PowerPointで開いて確認する必要がある．特に `pptx-render` では数式中の関数名（Hyponyms，exp等）が斜体で描画されたが，OMML上は立体（`m:sty p`）として指定している．
4. **発表者ノート**：作成していない．必要であれば各スライドの説明原稿を追加できる．
5. **生成スクリプトの依存**：`slides/build_slides.py` はpptxスキルの `add_slide.py` と `clean.py` を環境変数 `PPTX_SKILL_SCRIPTS` で参照している．
6. **ai-agentによる検証**：`tokens.json` が存在しないため，slideエージェントによるスタイルの検証は実行していない．
