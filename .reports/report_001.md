# report_001：論文「物体領域検出とカテゴリアノテーションの分離に基づく，WordNetを用いた粒度可変物体アノテーション」の再現実装

## 1. 概要

`main.pdf` の提案パイプラインを公開済みの学習済みモデルで実装し，論文4章の実験（4.2節〜4.7節）を4つの実験（ex001〜ex004）として再現した．
提案手法は学習を伴わないため，すべての実験は推論と評価のみで構成される．
主な結論は以下のとおりである．

| 論文の主張 | 再現結果 |
| :--- | :--- |
| オープンボキャブラリなVLMが必要（ResNet50-IN1k vs CLIP，有意差あり）（4.2節） | 再現できた．全指標で $` p < 10^{-11} `$ ．CLIP-RN50とCLIP-ViT-B/32の差は一部の指標のみ有意という点も一致した |
| DETRの位置検出精度はOWL-ViT・Grounding DINOと同等（4.3節） | 傾向は再現できた．平均最良IoUはDETRが最良（0.705 vs 0.517 / 0.546）．ただし選定した4画像では全手法のRecallが1.0を下回った |
| パイプライン全体でTop-1 0.647，Top-5 0.907（4.4節） | 最良の設定でTop-1 0.604，Top-5 0.894．論文に記載のない前処理の設定に強く依存する |
| WordNet深さ0→1で確信度が大きく低下（4.5節） | 再現できた（0.642→0.442，論文 0.695→0.477）．深さごとのインスタンス数も論文とほぼ一致した |
| COCO外の語へのアノテーション，灯台での検出失敗，giraffe→okapiの問題（4.6節，4.7節） | いずれも再現できた |

## 2. 実装と実験条件

### 2.1 パイプライン

画像 $` {\mathbf X} `$ に対しDETR（`facebook/detr-resnet-50`）を1回だけ実行し，スコアが閾値以上のボックス $` {\mathbf b}_k `$ を予測カテゴリを使わずに取得する．
ボックスにちょうど合わせたクロップ $` {\mathbf X}_k `$ をVLM $` f `$ に入力し，候補語彙集合 $` {\mathbb N} `$ 上の argmax を推定単語 $` \hat{v}_k `$ とする（論文の式(2)）．
深さ $` d \geq 1 `$ では，1つ浅い段階で選ばれたSynsetの直接の下位語集合を候補語彙とする（論文の式(3)）．
CLIPのプロンプトは "a photo of a {w}"，スコアはlogit scale付きコサイン類似度のソフトマックスである．
詳細なファイル構成は `document.md` を参照されたい．

### 2.2 論文に記載がないため本実装で決めた設定

| 項目 | 本実装の設定 |
| :--- | :--- |
| ResNet50-IN1kの重み | torchvision `IMAGENET1K_V1`．候補語は末尾語をWordNetの `morphy` でレンマ化し，小文字化したクラス名と完全一致した場合のみそのクラス確率をスコアとする |
| タスクBの語彙抽出 | spaCy `en_core_web_sm` 3.8.0で品詞が NOUN / VERB，アルファベットのみ，ストップワード以外のトークンのレンマ |
| COCOクラスとSynsetの対応 | `programs/common/wordnet_utils.py` の `COCO_TO_SYNSET`（定義文を確認して手動で決定．例：cow→`cattle.n.01`，stop sign→`street_sign.n.01`） |
| 下位語の候補語 | 直接の下位語Synset（`hyponyms()`）の先頭レンマ名．表記の重複は除く |
| ex002の4画像 | seed=42の500枚の順序で，GTが2〜3件の画像の先頭20枚から，GTの合計がちょうど10件になる最初の4枚の組（画像ID 107554，210299，98520，517687） |
| OWL-ViT / Grounding DINOの設定 | テキストクエリはCOCO 80クラス名．OWL-ViTは閾値0.1，Grounding DINO（tiny）は box 0.35 / text 0.25（80クラスを40クラスずつ2回に分けて入力）．どちらもクラス間NMS（IoU 0.5）でクラス非依存のボックスとする |
| ex003のDETR閾値 | 0.5，0.7，0.9，0.97を比較 |
| ex003のGTとの対応付け | ハンガリアン法でIoU 0.5以上の1対1対応 |
| クロップの前処理（ex003） | `center`：クロップをそのままCLIPの標準前処理（短辺リサイズ＋中央切り出し）に入力する．`pad`：クロップを黒で正方形にパディングしてから入力する．どちらの方式でもボックス外の画像内容は含めない |
| 追加22語（ex004） | penguin, helicopter, kangaroo, camel, lighthouse, dolphin, whale, shark, eagle, owl, parrot, flamingo, tiger, lion, monkey, gorilla, panda, deer, fox, rabbit, squirrel, castle |
| ex004の画像 | Wikimedia Commonsの固定のファイル名（`programs/ex004_open_vocab_qualitative/data.py`）．ライセンス情報は `datasets/ex004_open_vocab_qualitative/open_vocab_meta.json` に保存 |

### 2.3 実行環境

NVIDIA GeForce RTX 4070 Ti（12GB），Python 3.11，torch 2.7.1+cu128，transformers 4.53.2，open_clip 2.32.0 で実行した．
論文の実行環境はRTX 3090である．
各実験は単一プロセスでピークVRAM 3GB未満，ピークRAM 4GB未満であり，所要時間はex001が40秒，ex002が34秒，ex003が全24条件で330秒，ex004が約1分であった．

## 3. ex001：オープンボキャブラリなVLMの必要性（論文4.2節）

`programs/ex001_coco_val500_image_word/`，結果は `outputs/ex001_coco_val500_image_word/` に保存した．
評価対象は500枚で，GTカテゴリが空の画像を除くとタスクAは491枚になる．
$` |V_A| = 80 `$ ， $` |V_B| = 1371 `$ であり，論文の $` |V_B| = 1452 `$ よりやや少ない．

| タスク | 手法 | P@1 | R@1 | P@5 | R@5 | 論文 P@1 | 論文 R@1 | 論文 P@5 | 論文 R@5 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| A | ResNet50-IN1k | 0.216 | 0.091 | 0.069 | 0.123 | 0.255 | 0.095 | 0.084 | 0.132 |
| A | CLIP-RN50 | 0.855 | 0.431 | 0.316 | 0.659 | 0.838 | 0.397 | 0.334 | 0.649 |
| A | CLIP-ViT-B/32 | 0.855 | 0.433 | 0.328 | 0.687 | 0.822 | 0.385 | 0.350 | 0.678 |
| B | ResNet50-IN1k | 0.294 | 0.024 | 0.100 | 0.041 | 0.350 | 0.027 | 0.104 | 0.040 |
| B | CLIP-RN50 | 0.528 | 0.045 | 0.334 | 0.139 | 0.454 | 0.035 | 0.306 | 0.118 |
| B | CLIP-ViT-B/32 | 0.534 | 0.045 | 0.352 | 0.148 | 0.444 | 0.035 | 0.313 | 0.121 |

![ex001](../outputs/ex001_coco_val500_image_word/fig_metrics_comparison.png)

上図は論文の図2に対応し，誤差棒は画像単位のブートストラップ95%信頼区間（ $` B = 1000 `$ ）である．
タスクAの値は論文と±0.05以内で一致した．
タスクBではCLIPのP@1が論文より約0.08高く，ResNet50-IN1kは約0.06低い．
この差は，語彙抽出（spaCyのバージョンやストップワード除去の有無）によって $` V_B `$ が異なることが原因と考えられる．

Wilcoxon符号付き順位検定（`table_wilcoxon.csv`）の結果，ResNet50-IN1kとCLIP系の間ではタスクA・タスクBの全指標で有意差があり，最大のp値はタスクBのR@1における $` 2.2 \times 10^{-12} `$ であった．
CLIP-RN50とCLIP-ViT-B/32の間では，P@1とR@1に有意差はなく（ $` p \geq 0.53 `$ ），P@5とR@5のみ有意であった（タスクAのP@5で $` p = 0.038 `$ ，R@5で $` p = 6.3 \times 10^{-4} `$ ）．
「学習手法・語彙設計の要因がモデル構造の要因より支配的である」という論文の結論は再現された．

![ex003 accuracy](../outputs/ex003_coco_val500_pipeline/fig_pipeline_accuracy.png)

上図の破線が論文値である．
最初に実装した設定（閾値0.9，前処理`center`）ではTop-1が0.506にとどまった．
誤分類を集計すると，person → tie（53件），baseball glove（23件），baseball bat（22件），tennis racket（22件）など，人物のクロップが身に着けている物や持っている物に分類される誤りが多かった．
また，アスペクト比が3以上のクロップでは正解率が0.38まで下がっていた．
CLIPの標準前処理は短辺をリサイズしてから中央を切り出すため，細長いクロップでは物体の一部が失われる．
クロップを黒で正方形にパディングすると，ボックス外の内容を加えずにTop-1が約0.08改善した．
ただし，その後の分析（report_002）で，改善は人物以外のクラス（閾値0.9で0.560→0.677，bottle 0.344→0.844，car 0.378→0.581等）によるものであり，人物クラスの正解率はほぼ変わらない（0.395→0.402）ことを確認した．
person → tie 等の誤りは前処理ではなく，人物が身に着けている物や持っている物にCLIPが反応することが主因である．
DETR閾値を0.97にすると，対応インスタンス数（1519件）が論文の1466件に近くなり，Top-1 0.604，Top-5 0.894 となった．
Top-5は論文値との差が0.013まで縮まったが，Top-1にはなお0.043の差が残る．
残りの差の要因（論文で用いたCLIPの実装・前処理・インスタンスの選別条件）は特定できていない．
パイプライン全体での比較でも，ResNet50-IN1k（Top-1が0.09以下）とCLIPの間には大きな差があり，4.2節の結論と整合する．

## 8. 未解決の論点と次に検討すべき作業の候補

1. **Top-1の残差（0.604 vs 0.647）**：論文で用いたCLIPの実装（Hugging Face `openai/clip-vit-base-patch32` か open_clip か），クロップの前処理，評価インスタンスの選別条件（1466件の内訳）が不明である．クロップの前処理（パディング色，正方形へのリサイズ，プロンプトのアンサンブル）を追加で比較すれば，差の要因を切り分けられる可能性がある．
2. **ex002の規模**：4画像・10インスタンスでは統計的な比較ができない．500枚全体で3手法のRecall@IoU0.5と平均最良IoUを比較し，Wilcoxon検定を適用することが望ましい．検出の閾値も論文に記載がない．
3. **タスクBの語彙の差（1371語 vs 1452語）**：ストップワード除去の有無など，抽出条件を変えて論文の語彙数に合わせる検討が残っている．
4. **WordNet階層のフィルタリング**：giraffe → okapi，Indian elephant → white elephant のように候補が1語しかない分岐で確信度1.00の語が選ばれる問題に対し，そうした分岐の打ち切りや，非視覚的な語義・絶滅種の除外（論文5.4節の今後の課題）を実装し，深さごとの確信度がどう変わるかを評価することが次の候補である．
5. **候補語彙に正解がない領域の棄却**：helicopterの吊り荷のような領域に対する確信度の閾値処理を，ex003の確信度分布に基づいて設計できる．
