## 3. 論文作成のために追加で行った分析

論文の記述の根拠として，既存の出力（`instances.json`，`annotations.json`）に対して以下の集計を追加で行った．
新たな推論は行っていない．

### 3.1 クロップの前処理の効果の内訳

`outputs/ex003_coco_val500_pipeline/CLIP-ViT-B32/` の center と pad を同一インスタンスで比較した．

| 集計（CLIP-ViT-B/32） | center | pad |
| :--- | :---: | :---: |
| 全体のTop-1（ $` \theta = 0.9 `$ ） | 0.506 | 0.587 |
| 人物以外のTop-1（ $` \theta = 0.9 `$ ） | 0.560 | 0.677 |
| 人物のTop-1（ $` \theta = 0.9 `$ ） | 0.395 | 0.402 |
| 高さが幅の2倍以上のクロップのTop-1（ $` \theta = 0.9 `$ ，433件） | 0.441 | 0.545 |
| 人物のTop-1（ $` \theta = 0.97 `$ ） | 0.377 | 0.383 |
| bottleのTop-1（ $` \theta = 0.97 `$ ，32件） | 0.344 | 0.844 |
| carのTop-1（ $` \theta = 0.97 `$ ，74件） | 0.378 | 0.581 |

$` \theta = 0.97 `$ では，padによって正解に転じたインスタンスが217件，不正解に転じたインスタンスが97件であった．
パディングによる改善は人物以外のクラスによるものであり，person → baseball bat / tie / tennis racket 等の誤りは前処理では解消されない．
これに伴い，report_001の5.1節の「縦長の人物クロップでは胴体付近だけが残り，ネクタイ等の付属物が支配的になる」という説明は誤りであったため訂正した．

### 3.2 WordNet階層における単一候補の分岐

`detr_threshold0.97_crop_pad` の917件について，深さ1以降の全1188段階のうち209段階（約18%，208インスタンス）で候補語彙が1語のみであった．
CLIPのスコアはソフトマックス（論文の式(6)）であるため，これらの段階の確信度は必ず1.00になる．

| 深さ | 段階数 | 単一候補 | 平均確信度（全体） | 平均確信度（単一候補を除く） |
| :---: | :---: | :---: | :---: | :---: |
| 1 | 784 | 80 | 0.442 | 0.378 |
| 2 | 328 | 110 | 0.715 | 0.571 |
| 3 | 54 | 10 | 0.577 | 0.481 |
| 4 | 18 | 9 | 0.755 | 0.511 |
| 5 | 4 | 0 | 0.406 | 0.406 |

深さ2以降で確信度が「回復」して見える現象の一部は，単一候補の分岐によるものである．
頻出する単一候補の語は okapi（28件，giraffe），spindlelegs（24件，person → thin person），moped（18件，motorcycle → minibike），gamp（13件，umbrella）であった．
また，person の深さ1では suspect（20件），thin person（24件），visually impaired person（9件）など，外見から判断できない語が選ばれていた．

## 4. 再現対象の論文（`main.pdf`）との主な違い

作成した論文は再現実験の実測値に基づくため，以下の点で `main.pdf` と異なる．

- Top-1/Top-5正解率は 0.647/0.907 ではなく 0.604/0.894 である．
- クロップを正方形にパディングする前処理（式(3)）を手法として明記し，その効果を4.4節・5.2節で示した．
- 検出スコアの閾値 $` \theta `$ を明記し，0.5〜0.97で比較した．
- 4.3節では，選んだ4画像で全手法のRecallが1.0に達しないことと，その原因を記載した．
- 4.5節・5.3節に，単一候補の分岐の頻度と，それを除いた確信度の分析を追加した．
- 定性結果の具体例（kangaroo → musk kangaroo，helicopterの吊り荷 → backpack 等）は再現実験で得られたものに置き換えた．

## 5. 未解決の論点と次に検討すべき作業の候補

1. **著者情報と投稿先**：著者名・所属はプレースホルダである．投稿先が決まった場合，ページ数制限に合わせて分量を調整する必要がある（現状9ページ）．
2. **英文アブストラクト**：テンプレートの和文形式に合わせて和文の概要のみを記載した．投稿先が英文アブストラクトを要求する場合は追加が必要である．
3. **ex002の評価規模**：論文中でも「統計的な結論を得るには評価規模の拡大が必要」と記載した．500枚規模の比較を行えば4.3節の主張を強化できる．
4. **Top-1正解率の改善**：人物クラスの正解率（約0.38）が全体の精度を制限している．プロンプトの設計や，他の検出領域との包含関係を考慮した手法の検討が考えられる（論文5.5節の第五の課題）．
5. **WordNet階層のフィルタリングの実装**：論文で今後の課題とした単一候補の分岐の打ち切りや，外見から判断できない語の除外を実装し，深さごとの確信度の変化を評価できる．
6. **ai-agentによる検証**：`tokens.json` が存在しないため，documentationエージェントによる論文PDFの検証は実行していない．
