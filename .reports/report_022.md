# report_022：評価を主張に必要なものに絞る整理（論文・スライド）

## 1. 概要

`paper_2026B` と `slides_2026B.pptx` の評価が多すぎるという指摘を受け，主張に必要な評価だけを残した．

- **新しい実験：** 行っていない．表の値は，ex015，ex015a，ex015b の既存の出力のうち，元の分割（seed 42）のテスト用の画像の値を使った．
- **質問への回答：** LVISとOWLv2を使う理由はチャットで回答した．論文には，LVISを使う理由と「学習時に無い物体」の定義を追記した．

## 2. 残した評価と外した評価

| 区分 | 残した評価 | 用途 |
| :--- | :--- | :--- |
| 割合 | 検出，命名，細分化 | 結果を直感的に示す |
| 主指標 | AP_strict | 上位語に部分点を与え，GTと対応しない出力は全て誤りとする |
| 既存研究との比較 | AP_exact | LVISのカテゴリまで正しい出力のみを正解とする |
| 上限の目安 | AP_fed，hF_fed（各表1列のみ） | LVISの注釈が網羅的でないため |
| スコア | ECE（出力全体，経路上の各単語） | スコアの値が正解率と一致するか |
| 分析 | 同じ領域での命名の比較，誤りの分解（oracle の数値を添える） | 集約の効果と誤りの要因 |
| ばらつき | ブートストラップの95%信頼区間 | 差が偶然でないか |

| 外した評価 | 理由 |
| :--- | :--- |
| hF（GTと対応しない出力を除くもの） | 誤りを数えないため甘すぎる |
| AP_named | AP_strict と AP_exact の中間で冗長 |
| 追加の適合率 | 誤りの分解の「正しい命名」の割合と同じ量 |
| 予備実験の P，R，F値，mAP，平均IoU | 同じボックスでクラスの推定のみを比べるため，一致率 A で足りる |
| 画像を分け直した5回の試行 | ブートストラップと役割が重なる．結果は `outputs/ex015b_baselines_robustness/table_seeds.csv` に残っている |
| 表3（命名の方法の比較）の平均±標準偏差 | seed 42 の値とブートストラップの信頼区間に置き換えた |
