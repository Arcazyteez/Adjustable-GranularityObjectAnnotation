# report_032：ハイブリッド手法の削除と，VG.pdf の語彙・命名の手順の追加（ex020 の改訂）

## 1. 概要

- **目的：** order_031 の解釈を訂正し，VG.pdf の手法を現在の実験（ex020）に加える．
  - 使わないのは SigLIP だけである．VLM は各手法の F（新しい提案手法は Alpha-CLIP，古い提案手法は CLIP-ViT-B/32）にした．
  - 比較は3手法に絞った．
    1. New：OWLv2@20 + Alpha-CLIP + WordNet
    2. Old：DETR + CLIP-ViT-B/32 + WordNet
    3. YOLO11x 単体
- **ハイブリッド手法の削除：** ユーザーに確認した範囲（現在の実験から外す）で行った．
  - ex019・ex020 の YOLO11x + F（CLIP-B/32，CLIP-B/16，Alpha-CLIP）の構成を，比較・表・図から外した．
  - その結果フォルダと特徴のキャッシュを削除し，ex019 は再集計した．
  - ex006〜ex011 のプログラムと結果は残している．
  - OWLv2@20 + CLIP-B/32 と CLIP-ViT-B/16 の補助の比較も外した．
- **追加した VG.pdf のやり方：**
  1. VG の頻度に基づく語彙（3263語）
  2. 最上位の枠（40個）と WordNet による木
  3. 命名の手順3つ：木による細分化，平坦な命名，部分木の確率の合計
  4. 評価：VG.pdf の式(8)（深さ4以上の上位語の集合による hP，hR，hF）
- **主な結論（test）：**
  1. **部分木の確率の合計で，hF が最も大きく上がる．**
     - 正解ボックス + Alpha-CLIP：D = 0（COCO のクラスのみ）の0.266が0.639になる．
     - 古い提案手法：0.324が0.466になる．
     - 主な理由は，F が人物を持ち物の名前で呼ぶ場合でも，人物の下位語の確率が集まって person を出力できることである．正解ボックスの Alpha-CLIP では，命名の正解率が0.307から0.782に上がった．
  2. **部分木の確率の合計では，Alpha-CLIP が CLIP-B/32 を上回る．** 正解ボックスでの hF の差は +0.063（[0.034, 0.093]，$`p = 0.001`$）である．深さ0だけでは逆に −0.107 であった．
  3. **VG の木は，person の直下の候補の問題を緩和する．** 正解の経路を1段ずつ与えた場合，人物の1段目の正解率は WordNet の木（398語）で0.005，VG の木（136語）で0.097であった（Alpha-CLIP）．
  4. **検出から通すと，新しい提案手法は改善しても低い．** 新しい提案手法の hF は最良でも0.246（部分木の確率の合計）である．古い提案手法（0.466）と YOLO11x 単体（0.670）を大きく下回る．原因は report_030・report_031 と同じく深さ0の棄却（joint の θ0）である．細かい正解を持つインスタンス（85%が人物）の79%が，この棄却で残らない．
  5. **YOLO11x 単体は，細かい正解に対しても hF が最も高い（0.670）．** 細かい正解の85%が人物で，YOLO11x は人物を確実に検出し，person（粗いが正しい語）を出力する．ただし，COCO のクラスより細かい語は出せない（細分化の正解率0）．

## 2. 実験条件（`programs/ex020_coco_owl_alphaclip_granularity/`）

### 2.1 VG の語彙と木（`data.py`）

- **VG の語彙：**
  - Visual Genome の物体の注釈（v1.2．VG.pdf の v1.4 の物体の注釈は公開元に無い）を用いた．108,077枚のうち，COCO val2017 と重複する2,186枚を集計から除いた（VG.pdf と同じ枚数）．
  - $`n(s) \ge 10`$，深さ5以上の Synset とした（VG.pdf の式(2)）．
  - 3263語になった（VG.pdf は2964語）．これに COCO の80クラスの Synset を加えた．
  - プロンプトには，VG の注釈者が最も多く用いた名前を用いた．
- **最上位の枠：**
  - J = 40 とした．VG.pdf に一覧が無いため自分で定めた．VG.pdf に挙がる clothing，furniture，animal，light，natural object を含めている．
  - 語は，上位語の段数が最小の枠に割り当てた（VG.pdf の式(3)）．どの枠にも入らない808語（line，shadow など抽象的な語や部分）は，仮想的な枠に入れた．仮想的な枠を出力した場合は「出力なし」として扱う．
  - 頻出の語が仮想的な枠に入らないよう，各枠の Synset を加えた．例えば vehicle に conveyance を加えた（WordNet では train と bus が vehicle の下位語でないため）．
- **木：** 枠の中の各語は，上位語をたどって最初に出会う同じ枠の語彙の語を親とした（VG.pdf 4.2節の「枠＋WordNet」）．
  - 3315ノード，最大の深さ7である．
  - person の子は136語で，WordNet の person の直接の下位語は398語ある．

### 2.2 命名の手順

全ての手順で，深さ0の棄却 θ0 と残すボックスは ex019 と同じにした（命名の手順だけの比較）．

| 手順 | 内容 | dev の hF で選ぶ条件 |
| :--- | :--- | :--- |
| coarse | COCO の80クラスのみ（深さ0）．YOLO11x 単体はこの手順のみ | なし |
| wn_hyponym | COCO のクラスから WordNet の直接の下位語をたどる（これまでの手順） | θ_f（13通り）× D（6通り） |
| vg_tree | COCO のクラスから VG の木の子をたどる | θ_f × D |
| vg_flat | VG の語彙（＋COCO の80クラス）の平坦な命名．最大の確率が τ 未満なら出力しない | τ（13通り） |
| vg_subtree | 部分木の確率の合計．$`m_u \ge \tau`$ のノードのうち最も深いものを出力する（VG.pdf の式(6)(7)） | T ∈ {1, 1.5, 2, 3, 5} × τ（[0.01, 0.9] の12通り） |

語の確率は，F の学習済みの温度（約100）× コサイン類似度の softmax である．

vg_subtree は VG.pdf の提案手法の集約である．order_032 の「提案手法だけ使わない」が，この手順を指す可能性がある．そのため，結果を分けて示す．

### 2.3 評価（VG.pdf の式(8)）

- **細かい正解：** order_031 と同じく，COCO のキャプションの名詞の第1語義のうち，正解クラスの真の下位語とした（test 912件．85%が人物）．
- **集合 P と G：** 出力と正解の Synset 自身と，深さ4以上の上位語の集合である．COCO の80クラスの Synset は深さによらず含めた．person.n.01 の深さは3であり，除くと person の出力が全く評価されないためである．
- **指標：**
  - hP，hR，hF
  - 命名の正解率：出力が正解自身か，その深さ4以上の上位語である割合
  - 細分化の正解率：命名が正しく，COCO のクラスより細かい割合
  - クラスの正解率：全ての正解インスタンス3458件のうち，出力が正解クラスかその下位語である割合．枠のように COCO のクラスより粗い出力は誤りとなる．
- **評価の変更：** order_031 の評価（クラスから細かい正解までの経路の集合）から変えた．そのため，report_031 の数値とは直接比べられない．

## 5. 未解決の論点と次の候補

- **新しい提案手法の最大の課題は，深さ0の棄却である．** 命名の手順を変えても，人物が残らない限り hF は上がらない．
  - 候補：棄却のスコアを COCO の80クラスの確信度ではなく，部分木の確率の合計（例：枠の質量）や物体らしさだけにする．
  - 候補：OWLv2 の予算（@50）と組み合わせる．
- **部分木の確率の合計は粗い語を出しやすい．** COCO のクラスより粗い出力（枠）でクラスの正解率が下がる．
  - 候補：COCO のクラスより上には上がらない制約を加える．
  - 候補：深さ0で選んだ COCO のクラスの部分木の中で集約する．
- **「提案手法だけ使わない」の解釈：** vg_subtree が VG.pdf の提案手法に当たるため使わない，という意味であれば，比較は wn_hyponym，vg_tree，vg_flat となる．その場合の最良は以下の通りである．
  - 正解ボックス：vg_flat（Alpha-CLIP 0.334）または vg_tree（CLIP-B/32 0.375）
  - 検出から：New 0.230，Old 0.329（vg_tree）
- **評価の限界：**
  - 細かい正解はキャプションによるため，インスタンスと対応しない．
  - 第1語義の誤りが混ざる（例：controller）．
  - 85%が人物である．
  - VG の Synset の誤り（例：printer.n.01 が「人」の意味で person の子になる）．
  - 枠は自分で定めたもので，VG.pdf の枠と一致しない．
