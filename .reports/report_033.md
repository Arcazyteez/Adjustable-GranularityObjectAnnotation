# report_033：新しい提案手法の深さ0の棄却の判定の探索（ex021）

## 1. 概要

- **目的：** report_031・report_032 で分かった新しい提案手法（OWLv2 + Alpha-CLIP + WordNet）の最大の課題は，深さ0の棄却（残すボックスの判定）で人物のほとんどが落ちることであった．この判定を探索し，最適な判定を探す．
- **データ：** MSCOCO val2017 のみ（ex017〜ex020 と同じ dev 500枚，test 500枚）．検出・特徴・VG の木・キャプションによる細かい正解は，ex019・ex020 のものを用いた．
- **探索した条件：** 5つの要因の全ての組（120通り）を評価し，θ は dev で選んだ．
  - OWLv2 のボックス数：20個/枚，50個/枚
  - Alpha-CLIP の入力：context1.5，crop
  - 重複・部分の除去：なし，クラスごとの NMS，NMS + 包含
  - 棄却のスコア：joint，物体らしさ，VLM の確信度，部分木の確率の合計（mass），mass × 物体らしさ
  - 深さ0のラベル：COCO の80クラスの softmax（これまで），mass（部分木の確率の合計が最大の COCO のクラス）
- **主な結論（test．θ は dev の COCO の F値で選んだ）：**
  1. **新しい提案手法は，古い提案手法の F値を上回った．** dev の F値で選んだ最良の条件は以下の通りである．
     - 条件：OWLv2@50，crop，NMS + 包含，mass × 物体らしさ，mass ラベル
     - F値：現在の新しい提案手法の0.326から0.411に上がった（+0.085，$`p = 0.001`$）．
     - 古い提案手法（0.378）との差は +0.032（[0.007, 0.058]，$`p = 0.018`$），Top-1 の差は +0.116 である．
  2. **細かい粒度の hF は，古い提案手法と同程度まで回復した．** 0.255から0.461になった（古い提案手法は0.466．差 −0.005，$`p = 0.81`$）．人物の再現率は0.108から0.545になった（古い提案手法は0.517）．
  3. **効いた要因は，大きい順に棄却のスコア，深さ0のラベル，包含の除去，crop の入力，ボックス数である（1要因ずつ変えた比較，3.2節）．**
     - 棄却のスコア：mass × 物体らしさ（F値 0.411）が，joint（0.293）を大きく上回る．
     - 深さ0のラベル：COCO の softmax を mass にすると，F値が 0.352 から 0.411 に上がる．
     - 包含の除去：F値が 0.377 から 0.411 に上がる．
     - crop の入力：context1.5 の 0.365 から 0.411 に上がる．
     - ボックス数：@20 の 0.394 から @50 の 0.411 に上がる．
  4. **YOLO11x 単体（F値 0.719，hF 0.670）との差は大きいままである．**
  5. **hF で θ を選ぶと，棄却しない（θ = −∞）方向に偏る．** hF は正解に対応したボックスだけを評価し，誤検出では下がらないためである．総合の比較には，COCO の F値で選んだ θ を用いた．

## 2. 実験条件（`programs/ex021_coco_owl_rejection/`）

### 2.1 棄却の判定（`model.py`）

| 要因 | 水準 | 内容 |
| :--- | :--- | :--- |
| ボックス数 | @20，@50 | OWLv2 の物体らしさの閾値（ex019 で dev のスコアから決めた．0.149，0.076） |
| Alpha-CLIP の入力 | context1.5，crop | 長辺の1.5倍の窓，またはボックスにちょうど合わせて黒で正方形にパディング |
| 重複・部分の除去 | none，nms，nms_contain | 棄却のスコアの降順に，同じ深さ0のラベルの先のボックスと IoU 0.5 以上（nms），または面積の80%以上が含まれる（contain）ボックスを除く |
| 棄却のスコア | joint，objectness，vlm，mass，mass_joint | 確信度 × 物体らしさ，物体らしさ，確信度，mass，mass × 物体らしさ |
| 深さ0のラベル | coco，mass | COCO の80クラスの softmax の最大，または mass が最大の COCO のクラス |

- **mass：** VG の木（ex020）で，COCO の各クラスのノードの部分木に含まれる語の確率の合計（VG.pdf の式(7)の $`m_u`$，T = 1）の最大値である．
- **mass の利点：** F が人物の箱で tennis racket の確率を最大にしても，man，player，skier などの確率が person の部分木に集まる．
- **固定した条件：** 命名（vg_subtree の T，τ）は ex020 で選んだ条件に固定した．
- **θ の選び方：** dev のスコアの分位点41通りから，dev の COCO の F値が最大のもの（基準 f1）と，dev の hF が最大のもの（基準 hf）を選んだ．
- **比較対象：** 古い提案手法（DETR + CLIP-B/32，VLM の確信度）と YOLO11x 単体を，同じ評価のコードで再計算した．古い提案手法には mass ラベルの条件も加えた．
- **再現性の確認：** 現在の新しい提案手法（@20，context1.5，none，joint，coco）の F値は0.326で，ex019 の0.331とほぼ同じである．θ の候補の作り方だけが異なる．

### 2.2 評価

- **COCO の指標：** ex017 の metrics_func による，対応したボックスの Top-1，クラスを含めた適合率・再現率・F値．
- **細かい粒度の hF：** ex020 と同じ VG.pdf の式(8)．命名は vg_subtree．
- **人物の再現率：** クラス非依存，IoU 0.5．
- **差の検定：** 画像単位の対応のあるブートストラップ（1000回）．

### 3.2 要因の効果（最良の条件から1要因だけ変えた test の結果）

| 変えた要因 | 水準 | F値 | hF | 人物の再現率 |
| :--- | :--- | ---: | ---: | ---: |
| 棄却のスコア | joint | 0.293 | 0.277 | 0.111 |
| | objectness | 0.264 | 0.386 | 0.319 |
| | vlm | 0.227 | 0.222 | 0.087 |
| | mass | 0.363 | **0.481** | **0.683** |
| | **mass_joint（最良）** | **0.411** | 0.461 | 0.545 |
| 深さ0のラベル | coco | 0.352 | 0.466 | 0.556 |
| | **mass** | **0.411** | 0.461 | 0.545 |
| 重複・部分の除去 | none | 0.377 | 0.476 | 0.578 |
| | nms | 0.377 | 0.476 | 0.578 |
| | **nms_contain** | **0.411** | 0.461 | 0.545 |
| Alpha-CLIP の入力 | context1.5 | 0.365 | 0.437 | 0.475 |
| | **crop** | **0.411** | 0.461 | 0.545 |
| ボックス数 | @20 | 0.394 | 0.428 | 0.421 |
| | **@50** | **0.411** | 0.461 | 0.545 |

- **棄却のスコア：**
  - joint と vlm は，COCO の80クラスの softmax の最大値を使う．人物の箱では確率が持ち物と人物の下位語に分散するため値が低く，人物が棄却される．
  - mass では人物の部分木に確率が集まるため，人物が残る．
  - 物体らしさとの積をとると，背景や部分のボックスが減る．
- **深さ0のラベル：** 人物の箱を残しても，COCO の softmax では person と命名されない（現在の条件で0.001）．mass ラベルにすると，残った人物のほぼ全てが person になる．
- **重複・部分の除去：**
  - クラスごとの NMS は効果が無い．OWLv2 の検出ですでにクラス非依存の NMS（IoU 0.5）を行っているためである．
  - 包含の除去（同じ名前の大きいボックスの中の小さいボックスを除く）は，誤検出を減らして適合率を上げる（0.374 → 0.472．同じ条件の none との比較．再現率は0.380 → 0.363）．
- **入力：** crop は context1.5 より良い．context1.5 では周りの物体（持ち物）に引きずられやすい（report_031 の推測と一致する）．

## 5. 未解決の論点と次の候補

- **速度：** 最良の条件は OWLv2@50 を用いる．1枚あたりの時間は約0.49秒（ex019 の E3）で，古い提案手法（0.10秒）の約5倍である．速度を重視する場合は @20（F値 0.394，約0.35秒）も候補になる．
- **探索の範囲：** 条件の選択は dev で行ったが，120通りから選んでいる．test での古い提案手法との差（$`p = 0.018`$）は大きくない．別の分割や seed での確認が望ましい．
- **さらに改善する候補：**
  - mass の温度 T（今回は T = 1 に固定）
  - 包含の割合（0.8 に固定）
  - mass ラベルで選んだクラスの部分木に限った細分化
  - 名前によらない包含の除去
- **古い提案手法への同じ改善：** mass ラベルは古い提案手法では効果が小さかった（F値 0.378 → 0.369）．棄却のスコア（mass_joint）や包含の除去は，古い提案手法には試していない．公平な比較のため，古い提案手法でも同じ探索を行うかを決める必要がある．
- **YOLO11x 単体との差：** COCO の80クラスの評価では，依然として大きい（F値の差 −0.308）．
