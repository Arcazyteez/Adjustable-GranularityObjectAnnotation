# report_025：提案A（位置関係とWordNetの部分と全体の関係による領域の棄却）

## 1. 概要

- **目的：** 閾値以上の加えた領域の出力の誤りは，物体の一部（31.1%）と背景（32.6%）が大部分を占める．これらを再学習なしに棄却し，AP_strict を上げる．
- **方法：** 加えた領域ごとに「物体の全体らしさ」の特徴を求め，アノテーションのスコア s（式(9)，ロジスティック回帰）の特徴に加えた．
- **結論：** 効果は小さかった．
  - 位置関係の特徴は，AP_strict を ST と FT で約0.002上げた．95%区間は0を含まない．ただし ST-L では下がった．
  - WordNet の特徴は，どの重みでも精度を上げなかった．
  - 部分と判定した領域の大部分は誤りだった．しかし，物体の一部のうち判定できたのは9〜11%だけだった．
  - 物体の一部と物体の内側にある別の物体（人の衣服など）は，位置関係と語の関係だけでは区別できない．画像の内容に基づく判定が必要である．

## 2. 実験 ex016（`programs/ex016_wholeness_rejection/`）

### 2.1 条件

| 項目 | 内容 |
| :--- | :--- |
| 出力 | ex015b と同じ．ens の文章，人の役割を除く，β = 2，τ = 0.1，K = 100 |
| 命名の方法 | greedy（提案），flat（確率が最大の1語） |
| OWLv2 の重み | ST，ST-L，FT（ens） |

| ばらつき | 元の分割（seed 42）と，検証用とテスト用の画像を合わせて分け直した seed 0〜4 |
| 信頼区間 | 元のテスト用の画像で，画像単位のブートストラップを1000回（ST，FT） |
| 実行時間 | 約39分 |

### 2.2 全体らしさの特徴（`data.wholeness_features`）

YOLO11x のボックスでは全て0とした．スコアを変えるのは加えた領域だけである．

| 種類 | 特徴 |
| :--- | :--- |
| 幾何（4個） | 面積が1.5倍以上の YOLO11x のボックスに含まれる割合の最大値．同じく全てのボックスに含まれる割合の最大値．内側に含む加えた領域の数（log(1+n)）．画像内で最大のボックスに対する面積の比（log） |
| WordNet（2個） | **meronym：** 面積の80%以上を含む大きなボックスについて，その経路上の語の部分に出力した語が当たるか．部分の関係は part_holonym を推移的にたどる．人のボックスには homo.n.02 や body.n.01 を加える．例：car のボックス内の wheel．**part_word：** 出力した語が何かの部分を表す語か |

### 2.3 比較したスコア（`model.py`）

| 名前 | 内容 |
| :--- | :--- |
| base | 式(9) のみ．ex015b の calibrated と同じ |
| geom | base ＋ 幾何 |
| wordnet | base ＋ WordNet |
| full | base ＋ 幾何 ＋ WordNet．提案A |
| rule | base のスコアのうち，meronym が1の領域のスコアを0にする．規則のみ |

## 3. 結果

### 3.1 AP_strict（テスト用，greedy，元の分割）

括弧内は base との差の95%区間である．ST-L はブートストラップを行っていない．

| スコア | ST | FT | ST-L |
| :--- | :--- | :--- | :--- |
| base | 0.197 | 0.277 | 0.191 |
| geom | 0.200 [+0.002, +0.004] | 0.280 [+0.001, +0.004] | 0.189 |
| wordnet | 0.196 [−0.003, 0.000] | 0.274 [−0.005, −0.001] | 0.187 |
| full | 0.199 [0.000, +0.003] | 0.276 [−0.003, 0.000] | 0.187 |
| rule | 0.197 [0.000, +0.001] | 0.277 [−0.002, +0.001] | 0.191 |

- **分け直した5回の平均（ST，greedy）：** base 0.186 ± 0.003，geom 0.188 ± 0.004．元の分割と同じ傾向である．
- **AP_exact：** どの特徴でもほぼ変わらない．差は ±0.002 以内である．
- **ECE：** rule では悪くなった（ST で 0.028 から 0.033，FT で 0.014 から 0.026）．スコアを0にするため，校正が崩れる．
- **flat：** 同じく効果は小さい．ST の full − base は −0.001 [−0.002, 0.000] である．greedy と flat の差（full どうし）は，ST で +0.007 [+0.003, +0.011] である．

### 3.3 特徴の診断（`diagnosis_*.json`，テスト用の全ての加えた領域）

| 項目 | ST | ST-L | FT |
| :--- | :--- | :--- | :--- |
| meronym が1の領域の数 | 11,047 | 16,791 | 14,347 |
| そのうち正しい出力 | 1.3% | 0.9% | 2.1% |
| 物体の一部の出力のうち meronym が1 | 8.8% | 11.2% | 9.6% |

ST で，誤りの種類ごとの特徴の平均は次のとおりである．

| 種類 | YOLO11x に含まれる割合 | 面積の比（log） | meronym | part_word |
| :--- | :--- | :--- | :--- | :--- |
| 正しい | 0.63 | −4.7 | 0.036 | 0.19 |
| 物体の一部 | 0.86 | −5.0 | 0.088 | 0.25 |
| 背景 | 0.37 | −5.3 | 0.031 | 0.17 |

- **meronym が1の領域の内訳（ST）：** 物体の一部 61%，背景 31%．判定の適合率は高いが，再現率は低い．
- **正しい領域の位置：** YOLO11x のボックスに含まれる割合が平均0.63と高い．例えば，人の衣服や机の上の物である．そのため，位置関係で物体の一部を下げると，正しい出力も下がる．
- **WordNet の部分関係の不足：** 部分の関係が登録されていない語が多い．例えば ski_boot，tire，button は part_holonym を持たない．
- **LVIS のアノテーションの偏り：** 物体の一部と分類された領域には，LVIS で注釈されていない物体（衣服など）も含まれる．

## 6. 未解決の論点と次の候補

- **否定的な結果の扱い：** 提案Aは効果が小さかった．そのため，論文では「試したが不十分だった」ことと，その理由の分析として記した．主張はしていない．
- **次の候補（画像の内容に基づく判定）：**
  - 領域の周囲を広げて切り抜いた画像で1位の語が変わるかを調べる．変われば，物体の一部である可能性が高い．
  - 領域の特徴と含むボックスの特徴の類似度を使う．
  - OWLv2 の物体らしさの値と領域の特徴を使い，検証用の画像で小さな分類器を学習する．
- **物体の一部の定義：** 評価の「物体の一部」には，LVIS で注釈されていない物体も含まれる．真の誤りの割合を知るには，人手での確認が必要である．
- **ai-agent による検証：** `tokens.json` が無いため，行っていない．
